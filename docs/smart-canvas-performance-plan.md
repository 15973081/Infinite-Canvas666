# 智能画布性能优化任务书

## 边界与验收

仅优化智能画布前端；不改变生成请求、素材引用编号、Loop 执行和保存协议，不调用付费生成接口。已有视频/音频灯箱和关闭释放逻辑必须保留。用户已有的未跟踪文件不纳入提交。

每项流程：实现 → 专项测试及相关回归 → 更新本清单 → 独立提交。未验证的项不勾选。计数测试证明减少重复工作，不将其当成真实 FPS 提升百分比。

## 任务清单

- [x] S1 合并高频连线/小地图刷新：同帧多次请求只处理一次，保留布局后二次校正，立即刷新可取消过期队列。
- [x] S2 小地图复用：复用节点 DOM；视口变化复用节点布局，投影边界变化仍准确重投影。
- [x] S3 参数面板去重：一次面板更新只刷新一次素材区；未变化的素材列表保留 DOM，引用失效和编号更新不可跳过。
- [x] S4 局部节点更新：选择切换不重建全图；单节点状态更新保护其他节点、焦点和滚动。
- [x] S5 连线局部更新及计算复用：保留 SVG 元素、命中区和删除事件；移动只更新相邻连线；缓存限于安全的计算周期，避免过期拓扑。
- [x] S6 视野外媒体回收：仅降级安全媒体节点，保护交互/选中/运行/灯箱节点；回到视野正确恢复尺寸和组内滚动。
- [x] S7 大分组资源控制：保留素材索引、拖拽、删除及灯箱语义，按组内可见范围控制预览资源，不改变素材数据。
- [x] S8 计时器与最终回归：完成计时标签不维持无效定时器；浏览器隔离场景验证、相关自动测试、语法及 diff 检查。

## 后续评估（不盲目改写）

- [x] S9 删除局部更新：保留按钮先清空/键盘直接删除语义；多选仅一次撤销快照和更新；处理关联历史组、下游引用、灯箱释放与撤销恢复；无关节点 DOM/焦点/滚动不变。

差量撤销涉及历史恢复语义，本轮保留完整快照和 40 条上限；先处理确定的渲染热点。长生命周期依赖缓存同样不直接引入，优先采用单次刷新内索引/计算复用。
