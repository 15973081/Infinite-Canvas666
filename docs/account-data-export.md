# 个人数据中心与导出

成员菜单新增“个人数据”。统计当前账号在各空间的对话和附件，包括该账号已经退出或已经归档的空间中的本人记录。账号范围由登录会话决定，不能通过空间、成员 ID 或管理权限选择他人的数据。

点击“导出本人数据（ZIP）”，浏览器直接下载服务器生成的 ZIP，前端不把整个大文件读入 JavaScript Blob。生成期间保持页面打开；上传/清理未完成、源内容变化或会话失效会显示错误，可处理后重试。成功下载后再次导出可重新打开面板。

ZIP 包含 `conversations.json`（本人对话及其中的 Skill 文字快照）、`manifest.json`（本人基本资料、个人启用偏好、附件信息、校验值及保留边界）和 `attachments/`（本人附件原文件与预览）。文件路径使用服务端对象 ID；原始文件名仅写在清单中，不能形成目录穿越。本人明确共享过的附件仍属于本人，可随个人导出；他人共享给本人使用的原文件不会混入，已有对话中的引用信息仍保留。

完整导出不静默跳过未就绪附件。上传中、删除中或缺失版本需先处理，再重试。默认单次总数据限制 5 GiB，服务器可通过 `ACCOUNT_EXPORT_MAX_BYTES` 调整；同时受媒体临时容量和可用磁盘限制。超额返回 413，要求联系管理员进行完整导出，不返回截断的 ZIP。

服务端在生成前验证成员会话，逐个附件重新鉴权、下载准确版本并校验大小/SHA-256，发布响应前再次验证对话修订、对象版本/所有者/删除账本以及会话状态。内容变化返回 409，会话撤销返回 401，存储读取或校验失败返回安全的 502。导出包只在请求的 `MEDIA_TEMP_DIR/op-*` 中生成，响应结束和失败时随请求目录清理；不会把 ZIP 永久放入素材库或共享对象存储。响应为 `private, no-store`。

生成成功后记录 `account.data.export_prepared`，仅存成员、数量和字节数，不记录正文、密码、Token 或存储错误。该记录表示服务器准备好 ZIP，不能证明浏览器已经保存文件。

共享画布、空间素材、已发布 Skill、他人的对话、费用账本和必要审计记录由各自规则管理。个人导出不会删除这些记录，也不会擦除旧备份或模型供应商收到的内容。注销为独立的密码与文字确认操作，详见 account-closure.md，不能把导出当成已注销。
