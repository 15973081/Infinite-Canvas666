# 普通画布视频灯箱：截取片段

实现日期：2026-09-07。

## 入口与行为

- 视频灯箱右上角「截取片段」，位于下载按钮之前；图片/音频不显示此入口。
- 点击后在视频下方、提示词面板上方展开工具区；可输入时间、拖动双端范围、设为当前播放时间，以及预览片段。
- 输入支持秒数、`分:秒.百分秒`、`时:分:秒`；非法草稿会禁用预览与导出，编辑中的文本不会被自动格式化覆盖。
- 「另存为新节点」复用 `CanvasApi.trimSmartCanvasVideo` 及现有服务端 FFmpeg 截取接口。不修改原视频，不重建已有画布节点。
- 成功后在源节点右侧新增视频素材节点，记录来源与截取时间，灯箱及下载切换到新文件；新增节点可撤销/重做。
- 与智能画布相同，只截取 `/assets/`、`/output/` 本地素材。远程链接提示先保存到本地。
- 截取时可关闭灯箱；同画布的结果正常加入，但不会强制重新打开灯箱。若已切换画布或变为只读，不插入其他画布，并提示已生成文件的位置。
- 预览仅使用灯箱现有视频元素；暂停/收起/关闭/切换时停止预览循环，关闭时按原有机制释放视频来源。

## 验证记录

- 73 项 Node 回归 + 15 项 Python 音频回归 + 7 项现有智能画布截取测试通过；JavaScript 语法、`git diff --check` 通过。
- 新增自动测试覆盖时间解析、范围限制、编辑草稿、非法值、远程链接、共享预览、重复提交、只读、非破坏式导出、关闭/切换时异步返回、错误重试。
- 独立 QA 画布实际截取 1.25–2.50 秒：新增节点、灯箱新来源、下载请求均正确；原视频 SHA256 不变，原节点/文本框/灯箱视频 DOM ID 不变。
- 片段预览结束停止并回到起点；关闭后视频 src 为空、节点内 video 数量为 0；撤销节点数 3→2，重做恢复 3。
- 浏览器 1280×720、560×740 布局验收通过，错误日志为空。临时视口覆盖已重置，QA 画布已移入可恢复回收站；原用户画布未改动。
- 沿用已有重新编码行为，容器播放时长可能受帧率/音轨编码填充影响，不承诺逐帧零误差。
