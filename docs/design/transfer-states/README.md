# 画布加载与素材上传状态

本轮为经典画布、智能画布、素材库及在线生成补充临时状态展示，沿用现有主题变量、圆角卡片和上传协议。状态不写入画布文档，不需要数据库迁移。

- 打开画布时提示节点加载；节点中的图片和视频缩略图分别显示等待、加载、失败和重试。视频节点继续使用图片缩略图。
- 上传期间持续显示「当前素材上传中」；分片上传显示进度，传输完毕后继续等待服务器确认。失败提示保留到手动关闭。
- 上传到已有节点时，节点内显示上传提示；重新渲染仍保持提示。切换画布后忽略旧上传结果，避免写入另一画布。
- 素材库在开始上传时固定目标分类；在线参考图上传未完成时阻止生成，忽略已经被替换的旧上传结果。

- `tests/studio-unified.browser.cjs`：3 项。

另已通过在线生成与素材库成员媒体回归、画布模块回归，以及 JavaScript 语法和 diff 检查。
