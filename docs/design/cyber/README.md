# shadox 第一阶段视觉升级

采用已确认的「均衡工作台 + 赛博网格 + 字序索引」。升级范围是外层侧栏和画布首页，保留 iframe、画布业务模块、鉴权、任务恢复和原有 API。没有引入依赖或新的业务请求。

## 实现与视觉规范

- 侧栏宽 224px，收起 64px；新用户默认展开，已保存的展开/收起和当前页偏好继续有效。小屏使用抽屉、遮罩、Esc、焦点循环和返回焦点。
- 首页采用紧凑欢迎区、两种真实创作入口、最近画布和项目列表。少于四个画布或正在搜索/筛选时隐藏最近区，减少重复。
- 创作卡片采用 `(01) / CLASSIC`、`(02) / ASSISTED` 字序索引，细线展开、短下划线、加号旋转；项目悬停和搜索焦点使用微光。支持系统减少动态效果设置。
- 文件夹和排序使用自定义菜单；保留新建/重命名/删除/子文件夹、拖放移动、置顶、封面样式、回收站等真实功能。方向键、Home/End、Esc、Tab、点击外部均可操作。
- 封面统一 16:10；当前列表 API 没有缩略图字段，采用名称和网格占位，继续支持经典大字、杂志衬线、鼠尾草、墨色。没有逐个请求画布内容，也没有新增缩略图后端能力。
- 共用变量位于 `static/css/studio-tokens.css`；侧栏和首页分别由 `studio-shell.css`、`canvas-home.css` 管理。控件/卡片圆角 2px，弹窗 4px，间距采用 4/8/12/16/24/32px。后续迁移编辑器时可复用，当前不全局替换编辑器变量。

## 验证

- 159 项 JavaScript 回归通过，覆盖列表纯模型、文件夹/排序/搜索、跨 iframe 通信、主题过渡、业务模块、保存意图、权限和任务恢复。
- 19 项 Python 检查通过：统计模块、画布元数据、静态资源版本控制。
- 新增浏览器检查验证 320/390/768/1440px 深浅主题无横向滚动、自定义菜单的键盘焦点、移动抽屉、失败重试、减少动态效果，以及保存失败/成员退出拒绝时不会新建并丢弃原画布。
- Chrome 真实后端流程通过：登录 → 侧栏新建经典画布 → 添加并填写提示词 → 保存并返回 → 搜索/重新打开并确认输入 → 新建智能画布 → 进入智能编辑器 → 侧栏新建经过原有保存/权限流程返回创建弹窗。
- 次级文字和浅绿按钮的文字对比度均检查达到 4.5:1。
- 内置预览浏览器实际检查了首页、主题和经典保存流程；其 iframe 脚本导航停留，已观察到正确的智能画布导航事件。同一路由在 Chrome 后端集成测试中通过。
- 没有向真实模型提供商提交生成任务；任务恢复和权限通过现有自动化回归验证。没有实机手机触控、网络弱网、长时间运行或多人在线的实测。

自动化入口：`tests/studio-workbench.browser.cjs`、`tests/studio-workbench.live.browser.cjs`。后者只有显式设置 `STUDIO_TEST_URL`、`STUDIO_TEST_USER`、`STUDIO_TEST_PASSWORD` 时运行，目标必须是本机端口，并应使用隔离的 `APP_RUNTIME_DIR`。

## 性能抽样与后续

[完整数据](performance.json) 使用同一固定列表、减少动态效果、同一浏览器；每组测量六次重绘的中位数，单机抽样而非正式性能基准。

| 画布数 | 升级前重绘 | 升级后重绘 | 业务请求数 |
|---|---:|---:|---:|
| 100 | 54.2ms | 52.2ms | 5 → 5 |
| 500 | 252.0ms | 256.4ms | 5 → 5 |

首份可见内容更早出现，因为加载时已呈现创作入口和提示；这不等同于后端列表更快。500 项整表重绘仍耗时约 250ms，后续可以独立优化增量渲染/分页。

下一阶段建议先迁移编辑器的顶部操作、节点表单、选中边框和任务状态，再迁移素材库的筛选、预览和异常状态。缩略图能力单独评估保存时机、权限和缓存；不将参考站媒体素材当作项目资产。

## 改动保护与回退

开始前已备份这次涉及的原始文件到 `.local/studio-cyber-original`，包括原本未跟踪的 tokens 文件。用户已有的 `canvas-execution.js`、`canvas-session.js` 两个工作区文件 SHA256 保持一致；其他原有未跟踪文件保留。

本次升级单独提交，原有未提交内容继续保留。需要回退时，仅恢复本次改动文件及原始 tokens；新文件单独处理，避免整个工作区 reset/clean。编辑器业务模块和生产运行数据没有重写。
