# 无限画布：创作空间视觉方案

方向：延续登录页的深色空间、无限符号与细线质感。主张“入口有表达，创作区有秩序”。默认深色，同时提供纸白浅色方案。

## 结构
- 主导航收敛为 80px 图标栏，悬停提供名称，键盘焦点可见；小屏 58px。正式版保留固定展开偏好，避免纯图标影响新用户识别。
- 顶栏承载品牌、工作区切换和账号。状态信息降为辅助，不挤占创作空间。
- 画布目录取消居中悬浮面板，展开为标题、工具栏、文件夹和封面网格。大屏限制内容最大宽度，小屏单列。
- 大标题与静态无限线稿承担品牌表现；仅用于目录，进入编辑器后收起。
- 保留搜索、排序、刷新、回收站、创建和文件夹管理能力。概念稿重点展示主路径；正式接入时次级动作集中到目录工具菜单，不丢失原功能。

## 视觉语言
- 深色：底色 #101216，面板 #171a1f，文字 #ecede9，强调色 #d4edaa。
- 浅色：底色 #f3f2ed，面板 #faf9f5，文字 #242724；同一低饱和绿作为强调。
- 圆角只用于可操作控件与封面，控制在 6–14px；取消多层大圆角背景与重阴影。
- 内容标题、辅助文本和元数据建立三层字号，不依赖灰到看不清来制造层次。
- 封面样例由 CSS 绘制；实际项目使用已有缩略图，无封面使用本地抽象占位，不自动下载原图或视频。

## 扩展到其他页面
- 在线生图：左侧清晰参数区，右侧作品结果区，主生成按钮统一强调色。
- GPT 对话：阅读宽度受控，弱化消息外框，输入区域保留稳定视觉重心。
- 画布编辑器：使用同一控件和颜色，但背景尽量平静，只有选中节点与主动作着色。
- 素材库：复用封面网格、搜索和文件夹；批量操作按选择状态出现。
- 管理与计费：沿用字体、颜色和控件，不引入大标题艺术背景，优先保证数字可读性。

## 性能约束（实施目标，不是尚未完成的性能保证）
- 使用共享 CSS 变量和现有组件，不引入新的 UI 框架或字体包。
- 首页艺术图为静态 SVG；无常驻 requestAnimationFrame、粒子循环或 WebGL。
- 悬停动效只用 transform、opacity，时长约 160–180ms；支持减少动态效果。
- 禁止全屏 backdrop-filter 和大型动态滤镜；4K 下空闲时不执行装饰动画。
- 媒体按可见区域加载缩略图，视频由用户触发；与独立内容版本缓存配合。
- 主题先直接切换以验证无闪烁，再评估已有圆形过渡；不把整页遮罩动画作为必需体验。
- 正式接入后用真实 4K 设备测量交互帧时间、绘制成本、首次加载与缓存刷新流量。

## 交互原型
studio-concept.html 为单文件概念稿，系统字体、内联 SVG/CSS，无外部依赖。可以切换明暗、搜索、切文件夹、切列表/网格，演示创建画布。所有数据均为示例，不连接真实账户或项目。

## 落地顺序
先统一工作台外壳和画布目录；验证导航、权限、明暗、缩放、列表操作与大数据量，再扩展到编辑器控件及其他业务页。避免一次性重写现有业务逻辑。
