# 双画布查看模式媒体预览

2026-09-14，第 34 批。

## 实现

经典和智能画布共用 member-media-preview.js，协作栏增加“预览素材”。查看模式可直接点击图片、视频播放/回退按钮和音频入口，也可用 Enter 或空格打开。预览支持上一项/下一项、图片缩放与适合窗口、视频/音频原生播放控件；有 canvas.export 权限时显示下载原件。

预览从当前画布快照取节点与素材，不修改节点、图片尺寸、选中状态或任务。渲染地址继续使用 MemberMediaUrl 绑定成员/空间。只开放识别到的媒体入口，捕获节点事件阻止它们进入原编辑处理；其他节点控件保留只读限制。切入编辑时恢复原来的键盘、拖拽和无障碍属性。

权限或会话失效、维护停机/恢复、编辑代次变化、素材删除/替换及离开页面会关闭预览并释放媒体。每次打开/切换和下载前重新检查；未配置当前身份时不启动请求。视频缩略图不可用时仍可打开原视频。

浏览器验收额外发现智能画布图片尺寸测量调用 scheduleSave，导致仅查看就误报本地草稿。现在查看状态用临时副本更新显示布局；只有同一有效编辑会话中的测量才可更新文档，已替换节点和交接后的迟到加载不能保存。

## 并发临时目录清理修复

纯查看角色复验时实际捕获一次原图 500：check_budget 使用 Path.rglob 递归扫描临时目录，另一请求恰好结束并删除 op-* 子目录，异常发生在迭代器内部，原来的文件 stat 异常处理无法捕获。现改为 os.walk，仅忽略并发消失的路径，继续统计其他目录；权限和磁盘错误仍抛出，容量上限与磁盘保留量检查保持。

新增 4 项 Python 回归覆盖目录在扫描时消失、文件在读取属性前消失、权限错误与磁盘保留量。真实对象在 12 个并发线程下读取 120 次，所有原件校验和一致。使用修复版 8773 重新验证了纯查看成员的经典和智能原图预览。
