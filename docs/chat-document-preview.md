# DOCX / XLSX 解析预览与引用范围

上传后点击输入框附件上的“解析预览”。先查看提取的文字及遗漏提示，再保留“引用全文”或选择范围，点击“应用引用范围”。附件显示“已选范围”；取消本次引用不删除服务器原文件。历史消息中的 Office 附件也可打开预览。

DOCX 使用现有 MarkItDown 转换，按转换结果的 Markdown 标题分段，保留标题前的正文；没有被识别为标题的内容保留为正文段。选择的段落按源文档顺序发送，不包含未选段落。当前不提供版式还原，也不分析内嵌图片、图表、批注和修订的完整视觉效果。

XLSX 列出所有工作表、尺寸及隐藏状态。可选一张或多张表，每张表可填写 `A2:D20` 形式的矩形范围，留空表示整表。后端拒绝不存在、重复的工作表及越界、起止顺序错误的区域。文字保留原始行号和列号；合并单元格在覆盖区域显示锚点文字，即使锚点位于选择框外。公式读取文件缓存，缺少缓存时显示原公式，不执行计算。全文引用包含隐藏工作表，预览会明确提示。

预览只显示前 20,000 字符，以免页面过重；这不缩小实际选择范围。发送仍受附件文字上限和模型上下文预算约束。超过文字上限时预览显示截断提示，应缩小范围。区域过大或文件没有可读单元格时，预览保留工作表列表及错误提示，允许继续缩小范围；全文发送仍会按原有规则拒绝不可读取的文件。

选择仅保存文件 SHA-256、分段 ID 或表名与区域，不接受浏览器提供的解析正文。预算预检和两种聊天接口均重新鉴权、读取源文件、核验指纹并生成选中内容。指纹变化后要求重新预览；无效选择在保存历史、计费和请求模型前拒绝。历史消息保存原选择元数据，后续上下文重建沿用该范围。

解析结果只存在请求内存及浏览器当前预览中，没有新增永久解析缓存。读取和临时文件沿用原附件权限及请求结束清理机制；预览响应使用 `private, no-store`。共享或删除后，后续预览和解析重新鉴权，拿到原链接不能绕过成员权限。
