# 数据库画布租约：本地实现与协议

更新：2026-09-14。本批为 C2 后端实现；C2/C3 整体尚未验收完成，日常开发服务尚未切换成员模式。migration 008 仅在隔离 PostgreSQL 测试 schema 验证，开发库仍未应用 004–008。

## 已实现

- 每张画布持久保存锁代次、成员、登录会话、页面编辑会话、凭证哈希和数据库到期时间。默认租约 60 秒、建议心跳 10 秒；CANVAS_EDIT_LEASE_SECONDS 可配置在 15–300 秒范围。释放不删行、不归零代次；重新领取或接管递增，续租不递增。
- 锁定顺序为授权策略、画布行、租约行、依赖记录。首次领取也先锁画布行，因此多个连接或进程首次插入只能有一个有效持有者。重启连接池不影响代次。
- 身份来自成员 Cookie；编辑凭证绑定登录会话。同账号其他登录会话即使复制编辑凭证也不能保存或续租。公开状态只展示成员 ID、昵称、颜色头像、页面标识和租约版本，不返回 IP、登录会话标识或私密凭证。
- 取得租约时保存成员 auth_version。权限调整、角色变更、移出空间或归档会使旧版本租约失效；重新授予权限不会复活原凭证。此版本采取保守策略：即使是增加权限，也需重新领取编辑资格；改昵称不影响租约。
- 保存、元数据、目录移动、删除/恢复/永久删除、手动备份及恢复/删除、费用追加和费用恢复入口在实际事务中校验编辑凭证、代次和 base revision。新建无需已有租约，原子记录 created_by/updated_by；未知历史作者仍为空。普通保存与费用导入合并为一个事务。
- 关联生成入队需有效租约，同时记录任务发起人、画布 revision 和锁代次。释放不取消已入队任务；已有后台结果路径独立保存素材、历史及费用，不直接覆盖画布快照。任务列表重试查询仍可返回已存在任务，不再次付费。
- 正常释放校验最后确认的 revision，原子保存该版本快照、释放并留审计。旧凭证或重复释放不能重复生成快照。强制接管必须有 canvas.lock.takeover、确认、当前代次及非空原因；不会声称已保存旧页面未上传内容。
- 接手申请单独保存，目标页面提前获得仅属于自己的编辑凭证。持有者批准时检查申请到期、原代次、双方会话/权限版本以及已保存 revision，原子转移到指定页面；没有先解锁再争抢的窗口。重复批准、拒绝后的批准、过期请求均拒绝。
- 维护排空只允许排空前已持锁页面在原宽限内整体保存及续租；禁止新领取、接管、关联生成和其他共享修改。续租不能超过维护截止。进入只读、暂停访问或恢复检查会撤销旧租约并留事件；恢复开放后须重新领取。

## 成员 HTTP 协议

空间仍由 X-Workspace-ID 指定。画布路径为 /api/canvases/{id}。

| 请求 | 行为 |
|---|---|
| GET /edit-lease | 读取公开状态，不领取编辑资格 |
| POST /edit-lease/acquire，空对象 | 主动开始编辑；返回 edit_token、generation、revision |
| POST /edit-lease/acquire，takeover=self/force、expected_generation、confirm、reason | 本人换窗口或有权限的强制接管 |
| POST /edit-lease/renew | 校验凭证并续租 |
| POST /edit-lease/release | 校验确认的 revision，建立释放快照后结束编辑 |
| POST /edit-lease/transfers | 申请指定接手；返回申请 ID 和目标页面私密 edit_token |
| GET /edit-lease/transfers | 当前持有者查看待处理申请；申请人查看本登录会话的申请状态 |
| POST /edit-lease/transfers/{request_id} | approve=true/false；批准还需要 confirm=true |

写请求通过 X-Canvas-Edit-Token、X-Canvas-Generation、X-Canvas-Revision 携带凭证、代次和最后确认版本；整体 PUT 仍须提供 body.base_revision。续租允许省略 revision。目标页面等待申请获批后，从返回或状态查询取得新代次，再配合申请时收到的私密凭证编辑。凭证只在创建租约/申请时返回，服务端只存 SHA-256。

稳定错误码：canvas_protocol_required（428，旧客户端需升级）、canvas_locked（409，他人或本人另一页面持有）、canvas_lease_lost（409，凭证/代次失效）、canvas_revision_conflict（409，版本变化）、canvas_transfer_expired（409，申请失效）。维护与成员鉴权沿用已有错误码。公开冲突响应同样不含敏感身份字段。

## 验收与剩余门槛

本批新增 13 项实库/HTTP 用例，完整云集成 **111 通过**；Python 回归 **120 通过**（云测试单独运行），CJS **158 通过**。未调用真实模型，未应用开发库迁移。

新增实库/HTTP 用例覆盖 classic/smart 写入旁路、成员与空间隔离、同账号不同登录、凭证伪造、过期与旧释放重放、重授不复活、维护截止、关联任务、指定交接/拒绝/过期、管理员接管、保存与接管竞争、维护恢复、目录删除回滚。独立 Python 进程分别竞争首次领取和过期后领取，均只有一个成功。

原目录删除会顺带重分配其中所有画布。成员协议目前要求先持租约显式移出画布；缺少关联租约时整个删除事务回滚，不留下“目录已删、画布没移动”的半完成状态。多画布批量移出/删除的产品交互还需 C3 衔接，不能把此临时限制视为旧功能迁移完成。

仍需完成：两种画布共用客户端、空间选择、主动编辑/接手按钮、断线草稿与恢复、画布实时订阅/在线名单、后台结果加入画布、管理端协作事件展示、有效租约/未保存页面统计、备份恢复后撤销登录和编辑凭证的整体演练。旧 /lock 路由仍在成员模式拒绝；数据库租约 API 尚不供旧前端静默降级使用。当前维护后台仍将租约及未保存页面计数显示为未知，不声明可停库或发布。
