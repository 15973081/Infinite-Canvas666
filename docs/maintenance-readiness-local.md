# 维护发布检查报告与本地验收

日期：2026-09-14。管理平台升级 M3，第 25 批。

## 行为

独立维护中心在现有状态、租约和页面报告之外，新增逐项发布检查。报告经过当前平台/空间维护权限校验，业务成员的最小维护状态接口不包含管理检查、备份记录或执行占用明细。

检查范围包括新业务准入、执行中任务、所有任务状态下的有效/过期执行租约、尚未完成的付费准入记录、待核对任务、有效上传、处理中的上传、过期未收尾上传、有效画布占用、在线未保存页面、待核对页面以及排队/执行中的备份。暂停的持久队列单独列为待核对恢复兼容性，不自动取消或重新提交。

任务状态为 succeeded 不能代替执行器释放租约；过期上传不再从维护检查中消失。上传状态与处理租约可能同时计数，不能把不同检查项相加当作上传总数。备份统计按空间过滤，平台查看总量；不返回备份内部路径、凭证或其他空间的资源正文。

心跳分为在线、失联未确认退出和已记录退出。35 秒无心跳只表示状态未知，不视作进程停止。所有服务进程的实际状态仍需运维核验。

报告包含 observed_at、maintenance_versions、检查项和运维待办。它是读取期间的观察，既不冻结并发执行，也不颁发停止服务或数据库的授权；不存在持久停库许可。database_stop_ready 保持 false。空间报告的数据库停服判断为 not_applicable，不能作为全平台停库依据。

即使可观测数据项都通过，仍需核对未上报页面、本次发布备份及对象完整性、恢复方案、代码/数据库/队列兼容性。平台另要求实际停止工作台、任务与备份执行器、管理进程和其他数据库客户端，并在停库前验证真实连接和在途事务。管理平台自身仍依赖数据库，不通过网页停止数据库。

更改维护状态的确认摘要补充上传和在线未保存页面数量。原有状态转换、版本冲突和恢复确认规则保持；发布检查不会代替这些规则。
