交付标准是单一会话/资源所有者、完整操作入口、明确关闭/替换/暂停/销毁责任和原行为验收，不以清零全局绑定为目标。没有迁移 React、引入框架、合并 Classic/Smart、建立通用状态或渲染控制器。最后三轮代码提交为 `b4dfbd4`（输入应用）、`d9a0a33`（工作区缓存）及 `b296df0`（管理弹窗）。

复核全部当前 45 个跨模块多写候选和 20 个功能对象；其余声明按模块/内容/配置分组保留并记录静态证据。保留范围如下：

- 原文档 `canvas`、`nodes`、连接及 viewport 是现有业务数据。保存、远端应用、导入、撤销和任务回执仍有原写入路径，本轮没有将它们包装成另一个状态副本或宣称单写入口完成。
- Smart 当前 settings、默认/最近配置及运行快照仍保留原配置适配和持久化规则；UI 会话与提交后的任务输入分离。Classic 选择尚未收拢，明确留为后续独立评估。
- 保存计时器、dirty/in-flight、服务端节点/连接快照、undo 栈和抑制标记归原 document/session 协议；锁、租约、同步、级联和恢复协调可能比面板存活更久，不套用面板销毁规则。
- 原上传目标、分组上传落点、`@` 来源、拖放/resize、粘贴计时和连线 hover 属于剩余工作区握手/手势协议。保留原共享路径，明确协调职责；未宣称所有跨模块直接写入消失。
- 词库、素材及本地预设/分组/覆盖继续 library 原存储流程。UI 选择已封装，内容响应竞争、并发写回执与服务端版本是独立后续事项。
- Classic 管理页搜索、排序、删除确认及文件夹视图集中于入口；已有操作和刷新职责，没有外部组合字段收益，按计划保留。日志/计费计时、媒体源挂起恢复 WeakMap、模型/workflow 缓存及静态表仍由原模块持有。
- 共享画布根、运行/权限按钮和全局输入 DOM 仍有原宿主/任务更新。本轮只私有化明确属于已整理功能的专属 DOM，不宣称全部 DOM 引用已消除。

机器扫描排除了局部参数、函数 var、块作用域、catch 和 for 的同名引用；仍不追踪别名写入、Object.assign、动态 window 名、eval 或完整运行路径。人工复核候选不能证明不存在全部动态交叉写入。浏览器按 HTML ID 提供的同名 window DOM 属性未改变，生产代码不通过这些属性导出专属会话；既有素材所有者的渲染 DOM 接口继续按原 library 职责使用，不宣称所有功能对象都没有 DOM 查询接口。

## 生命周期与行为验收

打开状态与目标有效性分别表达；目标失效不能阻止 Escape/关闭与清理。旧加载、编码、上传和 UI 输入回执在关闭、重开、换目标、换画布、暂停或销毁后不能恢复旧会话。缓存返回按各原入口差异恢复监听/视图，不自动重开音频或播放；其他手势和面板监听不由当前功能删除。

已提交截取、导出、管理写入及原生成任务有独立完成语义。退出只限制旧 UI 与目标写回资格，不取消已经提交的服务端操作，不为清理 UI 改动结果顺序或保存/undo 核心。

基线继续覆盖首批 60 项、搜索不重绘画布、局部编辑与滚动、选择恢复、任务输入绑定/写回、只读门禁、实际媒体播放、真实 WebGL、分组切图、真实键盘退出、迟到加载/回执、重复绑定，以及 120 请求帧合并、100 次输入列表复用、2000 节点不变 DOM、420 节点删除/撤销保留播放媒体。

最终 **1206 项 JavaScript、51 项相关 Python 全部通过**；48 个生产脚本语法检查、差异检查、三个历史快照 SHA256 及当前盘点与源码一致性核对通过。阶段命令与细节见各自交付记录；最后三轮为输入应用、工作区缓存与管理弹窗，每轮独立提交便于回退。
