# Classic / Smart 工作区缓存与几何队列所有权

日期：2026-10-05；实施基线 `b4dfbd4`。本轮完成总计划第四阶段，保持脚本顺序、几何算法、局部刷新、虚拟化及保存流程。

## 移出的绑定与操作

Classic 的 `createClassicWorkspaceView()` 私有持有 7 个原入口绑定：连线 Map、输入列表 WeakMap、几何帧句柄/剩余帧数/全范围标志/节点集合以及视口刷新计时器。入口只初始化、绑定和在切画布/退出时通知重置，不再直接清连线 Map。

Smart 的 `createSmartWorkspaceView()` 私有持有 9 个原入口绑定：同步计算上下文、缩略图滚动 WeakMap、节点 HTML WeakMap、连线展示签名 Map、四个几何队列绑定以及视口刷新计时器。执行模块以 `smartConnectionsForComputation`、`smartNodeForComputation` 查询原节点和入边，不获得计算 Map 或可写上下文别名；入边过滤、历史输入及节点查找顺序沿用原流程。

两个功能对象各自冻结，只公开操作和冻结的调度状态。原有刷新函数继续薄委托；需要直接使用缓存的实现移入其所有者，不引入缓存 get/set 公共接口。Smart 的计算、绘制、局部刷新、滚动恢复及连线更新保持原实现；Classic 的连线 DOM 增删/复用和输入列表签名算法保持原实现。

节点、连接、选择、viewport、草稿、运行设置及任务记录继续共享原业务数据。暂存计算索引只在同步调用中创建，嵌套调用复用，finally 释放；视图销毁后任务查询仍可读取当前原数据，不以 UI 关闭中止已提交任务。

## 失效与清理

几何队列保留范围合并、全范围优先和第二帧修正；Classic 拖动结束的 flush 保留剩余校正帧，Smart 直接刷新继续取消旧校正。帧/视口回调核对画布 ID、节点数组及各自队列代次。重置、取消或 flush 后强制调用旧回调不能绘制，也不能取消新队列。

明确切画布时重置缓存并取消旧工作。相同画布内过滤/复制节点数组只取消旧队列，仍复用存活节点、输入容器及无关连线；节点对象替换继续使其事件闭包或输入签名失效。文档/撤销算法未调整。

Smart 聚焦节点的延迟局部刷新由所有者记录 focusout 监听和零延迟计时器，目标替换、节点脱离 DOM、换画布后不再刷新旧目标。重置/暂停/销毁解绑自身监听、取消自身计时器并清 DOM 标记；缓存返回对仍存活的待刷新节点补局部刷新，不丢弃编辑焦点或触发新保存。

重复绑定先解绑本功能 pagehide/pageshow 监听。缓存离开只暂停调度、保留 DOM 与缓存；返回补原视图校正，不重放用户操作或新增保存。永久离开释放自身监听、强引用与队列；后续绘制命令无效。其他选择、输入、工作区手势和媒体功能的监听不由缓存对象移除。

## 剩余范围

下一步按实际收益核对管理 UI，再新增当前逐项所有权与依赖复盘，保留三个历史快照。此次检查确认 Classic 管理页搜索/删除确认集中于入口，library 多选集中于管理逻辑；管理弹窗的 addEventListener 绑定和退出责任还需下一阶段具体处理，不能仅凭变量数量宣称完成。
