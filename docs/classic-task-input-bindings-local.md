# 经典画布任务输入绑定与自动回填验收

2026-09-14，C3 / TK-1 第三十八批。经典画布图片、视频生成入口现已使用保存确认、持久输入绑定和回填复验。智能画布仍未接入该协议；本批不代表整个 TK-1 完成。

## 实际生成链路

runGenerator 在等待图片尺寸前捕获源/目标及其上游输入；runVideoNode 使用同一预检。提交前强制完成当前保存队列，并使用编辑租约确认的 revision 创建带 canvas_target 的任务。保存失败、保存/摘要等待期间输入变化和失去编辑资格都阻止继续提交。

新任务回执与内存 operation 关联。输出节点的 pending 以不可枚举属性持有 operation，不写入画布 JSON；重新载入后的记录不能恢复原页面的回填权。图片/视频轮询在请求前后复验输入、原节点身份、编辑代次、task ID 和不可变回执，成功和失败收尾都受保护。未绑定或跨刷新记录保留在生成结果列表，供当前编辑者明确加入。

同批多图共享预期输入，前一张结果的自身修改会推进本批基线。没有独立输出节点的串联生成也绑定源节点自身，等待结果及最终写入均须核对。输入改变后的旧任务保持独立结果，运行令牌只释放本次的视觉忙碌标记，允许用户以新输入再次生成。

## 浏览器发现并修复的保存派生字段

首次浏览器验收完成两张图片回填后，再次生成触发输入冲突。真实保存会在本地素材 URL 所在字典补入 media_asset_id，而经典画布保存确认只替换外层文档，实时节点仍不含这个派生字段。

新增 v3 语义投影：当 url 明确为 /assets/cloud/ast_... 或 /api/media/ast_... 时，递归忽略由该 URL 派生的 media_asset_id；实际 URL、只有素材 ID 的引用以及外部 URL 附带 ID 仍参与比较。v1、v2 保留各自原投影和历史状态判断，不重写旧任务。普通 API 字段不变，无新增 migration。
