# 企业与空间管理

企业是客户组织边界，协作空间是企业内部的成员与资源边界。一个账号可以加入多个企业，并在各企业、各空间拥有不同权限。加入企业不会自动获得空间访问权限。

## 管理员授权

平台通过“企业租户 → 管理企业 → 企业成员 → 设置管理员权限”配置每位企业管理员。权限表单提供人员管理、项目管理、费用查看、综合管理四组快捷选择，支持逐项调整，并显示当前生效、保存后生效、保存后撤销或受企业规则限制的状态。

企业管理员实际可用的权限为三者交集：平台允许的企业能力、企业开启的能力、该管理员被授予的权限。平台关闭的能力，企业不能自行开启。企业管理权限不包含任何平台权限。

| 权限 | 范围 |
|---|---|
| 邀请普通成员 | 向邮箱发送本企业邀请 |
| 移除普通成员 | 移除普通企业成员及其在本企业的空间资格 |
| 任命管理员与设置权限 | 任命、降级、移除企业管理员，调整其管理权限 |
| 修改企业资料 | 修改企业名称；企业启停仍由平台管理 |
| 创建协作空间 | 在本企业创建空间并指定企业成员为初始空间管理员 |
| 归档与恢复空间 | 暂停或恢复本企业空间访问，保留资源 |
| 分配空间成员与角色 | 将本企业成员加入空间，选择内置或自定义空间角色，移出空间 |
| 管理空间角色 | 查看、创建和修改本企业空间的自定义角色；内置角色保持受保护 |
| 分配空间模型与默认模型 | 将平台已授权给本企业的模型分配给空间，设置空间默认模型 |
| 查看企业费用 | 查看本企业费用及所属空间费用 |
| 查看操作记录 | 查看本企业及所属空间的管理操作记录 |
| 调整企业权限规则 | 在平台允许范围内启停企业管理能力 |

“任命管理员与设置权限”默认不授予。具有此权限的企业管理员只能授予其当前有效权限的子集，不能修改自身的管理员身份和权限，也不能调整授权超出自身有效权限范围的管理员。邀请企业管理员还需要邀请权限。平台具有企业管理权限的操作者可以配置企业管理员，不受企业自身规则限制。

企业管理员的成员分配权允许授予本企业空间的角色；空间角色授予的是空间操作权限，不授予企业或平台身份。企业管理员的费用、审计、空间成员管理和空间角色管理能力仍受其企业授权约束，不能通过给自己分配空间角色恢复已撤销的企业管理能力。画布、素材和任务操作继续按空间角色判断。

管理员权限调整使用成员授权版本检查，保存后后续请求按新权限判断。后台失去费用或审计权限后不再展示相应入口或请求相关数据。企业和启用空间须保留有效管理员。

## 邀请与协作空间

邀请成员时可以同时指定一个协作空间及其角色，操作人须具有邀请和空间成员分配权限。邀请接口支持多个空间分配。接受邀请时重新检查邀请人的有效身份、管理权限、企业与空间状态以及空间角色是否仍可使用；权限撤销后不再兑现相应邀请。

已有企业成员接受邀请时保持其企业角色和管理员授权；已有空间成员保持原空间角色。新成员在同一事务中完成企业加入与空间分配。

空间成员分配窗口显示成员的当前角色，允许同时选择多个角色，包括自定义角色。空间角色窗口可创建和编辑自定义角色。空间归档保留成员、角色及资源，恢复时继续检查有效空间管理员。

## 数据库升级

应用新增 `045_tenant_admin_permissions.sql`，通过项目现有数据库迁移流程执行后启动新版管理服务。

- 已有企业管理员保留日常管理能力，管理员任命权限需要平台另行授予。
- 原“调整成员与空间权限”企业开关的状态同时写入新的空间成员分配、空间角色管理开关。
- 企业成员新增管理员权限集合和授权版本；邀请新增管理员权限集合与空间分配内容。
- 未接受的管理员邀请按邀请人的当前管理员任命权限重新判断；没有相应授权时，需要平台授权后重新邀请。

## 验证

租户集成测试：`python tools/cloud_test.py -k tenant --tb=short`。

桌面端权限交互：`node --test tests/management-tenant-permissions.browser.cjs`。

企业控制台导航与企业切换：`node tests/enterprise-console.browser.cjs`。

浏览器测试使用 Playwright 和本机 Chrome。接口测试使用隔离的本机测试数据库 schema。
