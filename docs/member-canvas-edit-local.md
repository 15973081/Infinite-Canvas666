# 双画布成员编辑：首批实现与验收

2026-09-14，C3 进行中。后续指定交接与强制接管进展见[交接实现记录](member-canvas-transfers-local.md)。使用 `.local/cloud` PostgreSQL 的隔离验收 schema；本批没有应用开发库迁移或启用真实成员模式。

## 已实现

- `canvas-edit-lease.js` 提供共用页面租约状态机。打开只查看；明确开始编辑后取得私有凭证、重载匹配的 revision，再允许写入。公开持有者状态不会授予编辑权，同账号的不同页面也不能共用凭证。
- 经典和智能画布接入“开始编辑 / 保存 / 保存并结束”、成员昵称、本人其他页面接管。查看时取消旧遮挡层，禁止节点编辑和键盘写入。旧局域网自动抢锁、退出 beacon 以及旧锁广播在成员模式不再生效。
- `CanvasApi` 的当前画布写入串行携带租约证明，整体保存补充已确认的 `base_revision`。关联图片/视频任务携带当前画布证明；不匹配的画布 ID 在发请求前拒绝。普通新建画布不要求旧画布租约。
- 保存与续租分开处理：心跳只延长有效期，不替换已确认的画布版本。客户端使用单调时间，并扣除往返耗时；服务端仍以数据库时间为准。过期、接管、会话暂停、网络异常或版本冲突停止写入，不自动合并重试。
- “保存并结束”先停止新编辑，确认保存后才释放；失败保留页面。迟到的成功响应不能在页面已暂停后清空草稿状态。切换经典画布、返回管理列表也先执行该检查。
- IndexedDB 草稿按成员、空间、画布、页面隔离，记录文档与基准版本，不保存租约 token。列表使用精确范围查询，提供导出；当前页面未保存时不能因返回列表而被清空。存储失败提示导出，不宣称已暂存。
- 成员维护状态转发给工作台 iframe；新加载画布继承当前维护状态。排空时停止新编辑并允许已有画布保存收尾，只读/暂停/恢复检查使页面停止写入，恢复正常不自动恢复旧编辑权。

## 验证

- `node --test tests/*.cjs`：181 项通过，其中新增 15 项覆盖公开状态不能授予编辑、超时/重载版本、写入排序、最后保存与释放、冲突/不确定响应、迟到响应、维护、实际 CanvasApi 接入和草稿作用域。
- `python\python.exe tools\cloud_test.py --tb=line`：113 项通过，含先前的数据库租约、跨进程争抢、指定交接和维护收尾测试。本批没有改变租约后端。
- `python\python.exe -m pytest -o pythonpath=. tests -q --tb=line`：120 项通过、113 云集成跳过、7 subtest 通过；云集成另行实际运行。
- 浏览器使用 `tools/workbench_preview.py` 创建的临时空间：两种画布均实际新增提示词、修改、保存并结束；智能画布重载后读到同一提示词且输入为只读；同账号第二智能画布页面显示原持有者，确认接管后可编辑，原页面提示资格失效、输入只读且内容保留。未运行真实生成或调用付费模型。
- 本地草稿的存储、范围查询与不持久化租约证明有自动测试；尚未把这些测试视为跨设备或完整浏览器故障恢复验收。
