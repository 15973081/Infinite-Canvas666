# 成员画布交接与强制接管

2026-09-14。接续[双画布首批实现](member-canvas-edit-local.md)，C3 保持进行中。

## 本批实现

- 他人编辑时显示“申请接手”，等待期间不会自动取得编辑权。当前编辑者看到指定申请，可以拒绝，或确认“保存并交接”。两种画布共用同一客户端和控件。
- 批准先停止新增编辑、确认保存，再向指定申请提交交接；不通过先释放再抢锁完成。保存失败不发送批准请求。申请过期或申请人权限改变时保持原持有者的有效编辑权；交接结果不确定时暂停写入。
- 接收方只使用本页发起申请时取得的私有凭据。读取到批准记录后，核对锁代次，再通过续租接口实际验证凭据，重载对应 revision 后才能编辑。同账号其他页面仅凭公开批准记录不能取得编辑权。等待时发生未保存更改则保留内容并提示导出，不自动覆盖。
- 具备 `canvas.lock.takeover` 的空间成员才显示管理员强制接管入口。确认框要求非空原因，提交当前代次和明确确认；后端再次鉴权并记录原因。提示明确说明不能保存旧页面未上传的内容。
- 维护开始撤销待接手的本页私有状态；排空期间不能批准新的交接。维护恢复不自动恢复旧编辑权。查看者的开始编辑按钮禁用。
