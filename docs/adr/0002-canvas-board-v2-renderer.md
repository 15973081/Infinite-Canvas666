# ADR 0002：CanvasBoard V2 渲染器

- 状态：已接受
- 日期：2026-08-18
- 范围：经典画布阶段 7

## 决策

CanvasBoard V2 使用自研 React 画布交互，不把 `@xyflow/react` 引入正式路径。旧 Board 在 V2 整体切换前继续作为唯一写入者，V2 仍置于独立功能开关后。

## 依据

- 两个原型都通过 200 节点、300 连线的性能门禁；三轮重绘中位数分别为自研 1.1 ms、`@xyflow/react` 3.0 ms、Legacy 313.0 ms。
- 自研原型通过选择、框选、拖动、缩放、创建连线和媒体 DOM 生命周期检查。
- `@xyflow/react` 的目标 Handle 在当前 `fitView` 混合节点画布中无法命中，未通过核心连线功能等价门禁。
- 组、Output 中转和复杂媒体节点仍需要产品自己的领域规则；继续适配库不会减少这部分代码，反而增加内部机制绕过。

## 后果

- 阶段 7 从 V2 Board 外壳开始，实现视口、选择、拖动、连线、快捷键和节点注册表。
- 删除连线、Group 成员联动、Output 中转、环检测和复杂媒体内容在对应迁移切片中补等价测试。
- Spike 保留为决策证据，不加载到生产默认页面；后续若核心需求变化，再用同一门禁重新评估。

详细样本和运行方法见 `docs/canvas-board-v2-renderer-spike.md`。
