# 管理平台任务处置：本地实现与验收

第二十二批为独立管理平台增加按空间的任务列表、状态筛选、详情与处置记录，追加 migration 014。工作台会话不能调用管理处置接口；成员需拥有目标空间的 task.review 权限，平台管理员也不能绕过空间授权。

## 操作规则

| 操作 | 条件与结果 |
|---|---|
| 继续结果入库 | 已有内部结果检查点，任务为待核对、失败或结果入库中且没有有效执行租约；重新进入结果入库，不发起生成 |
| 继续查询原任务 | 视频任务已有上游任务 ID，原托管供应商账号绑定一致，无结果检查点且没有有效执行租约；进入 polling，由业务 worker 查询原任务 |
| 取消未提交任务 | 排队或待核对任务，没有提交记录、上游 ID、结果检查点或历史提交不明标记，且具有可信发起人与托管账号绑定；标记 cancelled |
| 确认失败 | 待核对任务没有结果检查点或有效租约；管理员明确勾选已核实上游状态并填写原因，标记 failed |

操作必须主动选择并填写原因；任务任意更新（含领取和心跳）都会递增 review_version，旧表单拒绝执行。处置、回执和审计在同一事务提交；相同会话使用相同请求 ID 和原始参数重试，返回原回执，不重复处置。权限撤销后不能重放回执。

详情只返回必要状态、上游 ID、提交数量、账号匹配结果和处置历史，不返回请求正文、原始供应商响应、错误正文、签名地址、账号指纹、凭证或租约 token。处置不删除原任务、提交记录、检查点、费用或生成结果。

已有结果在空间排空时可继续入库。取消供应商空间分配后，持有效执行租约、具有内部检查点且账号绑定一致的任务仍可完成结果发布；账号发生变化时进入待核对，避免使用其他账号下载结果。结果恢复不会放宽新付费提交准入。

## 运行边界与剩余工作

用户正在使用的 8768/8769/8770 服务均返回 HTTP 200，保留原数据和当前会话，没有加载本批功能。该预览 schema 仍为 012，需要受控应用 013–014 后再加载新的管理与业务进程；开发库仍未应用 004–014。本地 .local TOS 模拟继续保留。

本批不支持手填上游 ID、猜测旧账号归属或盲目重新付费生成。缺失上游 ID 的不明提交、旧账号显式映射及完整恢复演练仍在 M4；备份管理、旧管理页面迁出和完整维护排空仍待完成。ComfyUI、ModelScope 及其依赖功能继续按用户要求弃用。
