第一批验证：234 项相关云测试、53 项文档及聊天单元测试、8 项浏览器测试通过。云测试使用隔离数据库与临时对象根目录，浏览器使用模拟接口，未调用真实付费模型或删除生产数据。

上下文预算批次验证：90 项供应商、Skill 与成员聊天云测试、61 项文档及聊天单元测试、9 项浏览器测试通过。另修复供应商恢复测试创建任务时缺少成员身份的旧夹具问题。后台删除的独立循环、TOS 完整对象键过滤及预览额度限制也已有专项测试。

删除账本及个人审计批次：41 项附件、备份及数据库恢复云测试，11 项账本和上下文单元测试，10 项浏览器测试通过。测试账本与对象目录均被强制隔离到临时目录。部署与恢复限制见 chat-deletion-ledger.md。尚未提交或部署到生产。

文档选择批次：60 项聊天、附件、Skill 和计费云测试，29 项文档、聊天错误、上下文与删除账本单元测试，12 项浏览器测试通过。另补充并通过解析器内容变化不能复用旧 DOCX 分段 ID 的单元测试；分段 ID 同时绑定分段文字。真实源文件验证 DOCX 分段和 XLSX 区域选择，实际 mock 上游请求校验排除未选正文。见 chat-document-preview.md。个人导出与注销及其他数据类型的备份删除重放仍未完成。

个人导出批次：30 项个人导出、私有附件及数据库恢复云测试，13 项浏览器测试通过。跨已退出／归档空间本人数据、他人隔离、共享附件归属、源变化、会话撤销、校验错误、超额和临时文件移除都有覆盖。浏览器实际原生 ZIP 下载、错误重试及手机布局已验证；见 account-data-export.md。注销仍待实现，当前改动未提交或部署。

注销与扩展重放批次已实现；上述个人导出批次的“注销待实现”仅描述当时状态。12 项专项云测试通过，含账号注销、最后管理员、进行中任务/他人引用保护、账本失败回滚、接受意图后事务中断的后台修复、真实旧备份恢复对话/Skill 原包/注销。完整云回归及最终要求审计进行中。

后续完成审计必须逐项验证完整目标，特别是恢复旧备份不会重新开放已删除附件、注销不能误删他人的共享数据、区域选择确实约束发给模型的正文、超额请求在保存历史和调用模型之前被拒绝。删除账本不能仅依靠会随数据库一起回退的表。


最终验证（2026-10-08）：完整云回归 499 项通过、1 项跳过；文档解析、选择、预算、删除账本、错误提示单元测试 37 项通过；浏览器及成员路由测试 25 项通过。新增删除错误分类的实际后台重试测试另行通过。完整云回归包含旧任务审核和图片恢复的真实成员身份/租约夹具修复。个人数据移动端表单经截图检查，无横向溢出。

完成审计：容量预留与跨空间统计、未引用筛选与确认清理、固定版本持久删除及自动重试、独立账本恢复重放、跨空间本人导出和受保护注销、DOCX/XLSX 指纹绑定选择、调用前上下文预算、本人隔离审计均已有实现及专项验证。旧备份恢复实测不会重新开放已删除的附件、对话、Skill 原包和注销账号；他人共享引用保护和超额请求不保存历史/不调用模型也有覆盖。

部署前必须应用 031/032 迁移、配置所有 API 与 worker 共用且不会随数据库恢复回退的删除账本、启动清理 worker。当前完整恢复仅支持 filesystem 包；TOS 原生全库恢复仍拒绝开放。账本不擦除旧备份字节；未发送附件自动到期、备份销毁期限、供应商留存和运维失败告警属于下一阶段策略与工程，不能将本地测试结果表述为生产验收。
