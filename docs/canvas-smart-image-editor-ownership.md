# Smart 图片编辑器：状态所有权与会话清理

日期：2026-10-04。原始盘点快照 `canvas-global-state-inventory.json` 保持不变。本记录承接 Classic 编辑器与退出缺口修复，范围仅为 Smart 图片编辑会话及其与普通预览的接口。

## 所有权

| 内容 | 唯一所有者 | 外部入口 |
| --- | --- | --- |
| 裁剪、画笔、文字、编辑内历史、宫格拆分／拼接、编辑缩放、图片资源与专属 DOM | `smart-media-editor.js` 的 `createSmartImageEditor()` | `smartImageEditor` 操作命令、冻结的 `state` |
| 当前图片目标、分组索引、模式、日志脱离画布的预览目标 | 同一编辑会话 | 打开、导航、切换模式、目标查询 |
| 普通预览缩放、平移、对比拖动与捕获 | `smart-results.js` 的 `createSmartPreviewGestures()` | 缩放、移动／结束、重置、暂停／恢复、销毁 |
| 预览媒体加载、对比候选与预览 DOM 呈现 | results 原功能 | 准备、设置来源、离开、释放、暂停预览；会话保护的回调 |
| 节点、全局选择、创建节点、保存、画布撤销 | 原 workspace／document／session | 图片编辑选中操作委托 workspace；原写回与节点创建流程保留 |

入口移出 31 个编辑／资源 `let` 绑定、5 个普通预览姿态／手势绑定。删除 `previewNavState` 与 `detachedEditPreview` 两个独立绑定：导航读取编辑器的同一个目标，日志预览通过 `openDetached()` 保存目标信息。相关常量、DOM 引用、内部数组与 Map 均不向外暴露。

冻结 UI 快照只有标量：`open`、`targetValid`、`ready`、`paused`、节点 ID、图片索引、数量、模式、缩放、工具、历史／文字／宫格计数。普通预览的 `pan` 是独立冻结副本。快照不返回 DOM、历史数组或可写编辑字段。浏览器按元素 ID 自动提供的命名属性不属于 JavaScript 状态绑定；所有权测试同时核对源码及真实页面。

`currentEditImage()` 与 `ensureSmartEditableImage()` 保留为 results 既有视频／全景消费者所需的具体桥接入口，分别提供有效内容目标和共享原图资源；它们不是 UI 状态修改接口，资源释放仍由编辑会话负责。没有复制图片、节点选择或普通预览姿态。

## 命令与目标规则

原 HTML／调用方函数名保留为薄委托。打开／关闭、模式与工具选择、编辑内撤销／重做、宫格操作及应用由编辑器完成；workspace 的共享窗口处理器只委托移动与结束操作，其他工作区手势监听保持原样。外部不再读取 `cropState` 或直接写编辑字段。

目标记录画布 ID、节点对象、图片索引、原始图片对象和展示来源。执行工具或接受异步结果前核对画布、节点仍存在、索引仍对应原图片及来源未改变；常规路径优先检查已记录的节点位置。日志预览明确标记为脱离节点集合的目标，保留原选择恢复规则。

`open` 仅表达面板会话已打开。`targetValid` 单独表达目标仍有效；`ready` 再要求原图已加载且会话未暂停。撤销、草稿恢复、同 ID 节点替换或画布清空后，可见面板仍能通过真实 Escape、取消或遮罩点击关闭；编辑与应用入口拒绝无效目标。实际节点删除沿用原主动关闭流程。

关闭、重开、切图、画布加载重置、暂停和销毁使旧会话代次失效。模式变更另外使旧编辑操作与预览回调失效，不阻断当前原图加载。PNG 编码与上传返回后分别核对来源，失效结果不写入图片、不创建输出节点、不关闭新会话、不触发保存。拼接另核对本次使用的分组图片及来源。

结果写回保留原流程：分组裁剪替换原索引，遮罩追加至原分组，扩图设置原尺寸参数与提示词草稿；拆分／拼接仍使用原节点创建操作。拆分／拼接各保留创建节点与应用后的两次 `scheduleSave()` 调用，保存合并机制不变。普通裁剪、扩图、画笔及遮罩的应用仍触发一次保存；打开、导航、模式切换与关闭不额外保存；原图首次记录自然尺寸时沿用原有保存触发。

## 清理规则

- 四组编辑控件监听及两组普通预览监听分别记录，重复绑定只替换自身记录。生命周期监听由编辑器持有，暂停保留返回监听，永久销毁解除。没有移除共享 workspace、素材库、全景控件或其他模块的监听。
- 编辑器追踪渲染与临时文字聚焦帧；关闭、暂停、重开及模式切换取消帧，回调执行时仍核对代次／模式操作版本。临时文字编辑器在移除前解除 input、keydown、blur。
- 拖动结束、取消、关闭与模式切换释放自己的指针捕获。共享窗口委托在没有相关手势时立即返回，避免闲置鼠标移动查询编辑 DOM。
- 宫格预览图片和导出加载分别记录。重绘解除被替换元素的回调；关闭解除来源并清空缓存，取消等待中的导出 Image 时同时结束其 Promise。缓存校验原始图片和来源，不仅校验索引。
- 关闭清空来源／加载回调、文字、宫格和编辑历史，绘制画布尺寸归零；释放当前原图对象 URL，解除素材加载状态监听与定时器，调用 results 既有预览媒体／全景释放入口。
- 缓存页面离开暂停会话、控件与媒体状态监听，保留已加载的编辑草稿；返回校验目标并恢复一份监听与视图。尚未完成的打开重新加载，旧回调不能恢复旧会话。全景仅调用原释放入口，不改渲染或导出算法。
- 永久离开销毁控件、生命周期监听和 DOM 缓存；销毁可重复调用，之后的打开与编辑命令不起作用。已提交上传继续完成，失效回执不会应用到新目标。

## 剩余范围与风险

保留 results 的对比开关、对比项索引和元信息内容绑定，以及视频截取、全景状态与既有工作区委托；没有为本轮扩展整个预览系统。视频／全景算法、生成工具任务、画布撤销、保存与权限核心、Classic 实现及脚本加载顺序无内容改动。

没有增加上传取消协议。已经提交而本地会话失效的上传可能留下未被引用的文件；同一有效会话内并发应用、跨客户端更新以及服务端内容版本一致性仍沿用原流程，单独处理。

浏览器接口为隔离夹具，未验收真实生成／对象存储服务、大尺寸图片性能或跨浏览器差异。缓存返回覆盖生产 pagehide／pageshow 处理器，不声称所有浏览器真实进入 BFCache。原盘点快照保留，后续阶段以减少状态耦合为主线。
