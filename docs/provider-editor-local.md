# 供应商配置界面与默认预设验收

2026-09-14，按旧项目 API 设置页重新整理独立管理平台的供应商配置。

## 使用方式

供应商页改为左侧平台列表、右侧配置区域，分为基本信息、API Key、火山素材库、模型列表和折叠的高级配置。火山引擎默认显示；地址、协议、8 个视频模型、ProjectName=default 和 Region=cn-beijing 沿用旧版。其他协议不显示火山专用凭证。

公共预设维护在 config/provider-presets.json。builtin 为默认可见平台，quickstart 为旧版快捷配置：APIMART、玉玉API、Agnes AI、FHL。快捷配置只提供旧项目已有的地址、协议和模型提示，不声明上游当前可用性、免费额度或价格。ComfyUI、ModelScope、Runninghub 不再提供。

首次填写地址与 Key 后保存，点击“拉取上游模型”，填写原因、拉取并勾选要追加的模型，再点击“追加所选模型”。已有模型、逐模型协议和价格配置保持；拉取本身不修改配置。视频规格价格、协议诊断、旧配置导入和空间分配入口保留。

内置预设在首次保存前是待配置展示，不通过读取接口写入数据库，不自动分配空间。保存过的同 ID 配置优先，包括自定义名称、模型和停用状态。仅保存后的供应商能够分配给空间。配置提交仍校验版本和权限，凭证不回显，留空保留，替换与清除不能同时选择；切换平台或管理范围时保护未保存修改。

## 本地凭证与重启

workbench_preview.py 在预览目录中持久保存 provider-secret.key，并让业务和管理子进程使用同一密钥。显式配置 PROVIDER_SECRET_KEY 时优先使用它；已有加密凭证却丢失原密钥时拒绝生成替代密钥。普通生产启动仍须按 managed-providers-local.md 配置主密钥。预设 JSON 不存放凭证。

备份预览时必须保留原密钥文件或外部配置的密钥；恢复不能用新密钥替代。--resume-schema 仍不自动迁移、初始化账号或删除数据。
