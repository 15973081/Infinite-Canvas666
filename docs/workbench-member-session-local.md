# 成员工作台前端接入与本地验收

更新：2026-09-14。当前完成成员入口与空间会话底座，M1/C3 整体仍未完成；开发服务未切换成员模式，开发库仍未应用 004–008。

## 当前实现

成员登录页面支持一次性激活、自行设置密码、返回已有账号登录，以及管理员重置后的再激活。激活成功使用服务端返回的账号登录，清空表单凭证；后续登录失败只重试登录，不重复消费激活凭证。共享入口旧模式仍保留其原有初始化行为。

成员模式的 HTML 在其他业务脚本前加载 member-session.js，请求等待成员验证和空间选择。首次不自动选取第一个空间；选择仅记在当前浏览器会话、对应成员的键下。明确链接指向未获分配空间时展示错误，不静默落入另一个空间。没有空间时可刷新列表或退出。

工作台工具栏可选择空间、修改昵称及颜色头像、退出登录。切换空间前等待现有页面的保存钩子，失败时留在原空间；成功后整个页面重新加载并移除旧画布 ID。iframe 继承父页面选定空间，独立页面分别验证账号及链接参数。现有普通/智能画布初始化等待会话就绪。

同源业务 fetch 自动携带 X-Workspace-ID 与 X-Member-ID；后者仅是页面身份约束，不是认证凭证。服务端始终先解析 Cookie，身份不一致拒绝读、写、退出和资料修改。跨站请求不加入这些头。实时连接带空间及成员约束，移除旧 client_id；普通工作台在线计数使用成员数。成员维护公告按服务端时间抑制旧消息；完整只读、租约和草稿联动仍待实现。

登录失效、空间撤销或账号变化后页面暂停新的业务请求，不清空当前内容；重新确认同一账号也不会静默恢复旧编辑凭证。后续 C3 协作客户端须接入暂停事件、实际编辑状态及草稿恢复。storageKey 提供成员与空间命名空间，但当前尚未完成所有历史前端缓存、剪贴板和草稿使用点的迁移。
