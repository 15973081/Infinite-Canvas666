# 智能画布图片工具

智能画布图片预览底部提供「生成全景图」和「生成深度图」。两者只使用当前选中的一张图片作为参考，复用现有图片模型、任务队列、编辑资格校验、结果恢复和计费流程。每次生成 1 张，新结果写入新的输出节点，不替换原图。

## 管理配置

1. 进入管理平台 → 图片工具，在右上角选择具体空间。
2. 分别配置全景图和深度图：启用状态、供应商、图片模型、画面比例、1K / 2K / 4K 清晰度、生成质量及提示词。
3. 填写修改原因并保存。供应商须已启用并分配到该空间，模型须已开放所选规格。

默认均未启用，不自动选择收费模型。配置存储在该空间的 `workspace_documents` 中，类型为 `image-tools`；沿用现有版本字段和管理审计，无新增数据库迁移。管理操作要求平台供应商配置权限及该空间读取权限。

全景图默认提示词要求球面等距柱状投影及左右无缝，建议 2:1。深度图默认提示词输出近白远黑的灰度相对深度图；这是图像模型生成的视觉结果，不包含物理距离标定。比例由管理员明确选择；模型实际支持的比例和质量取决于对应供应商。

## 提交与兼容

画布端读取 `/api/image-tools` 配置，只提交工具标识和配置版本。后端在计费及入队前校验配置、所属空间、供应商分配及原图可读性，并覆盖客户端模型、提示词、尺寸、质量与数量。若配置已更新则拒绝旧请求，让用户重新打开工具，不悄悄切换模型或规格。

已入队的任务保存当时的完整参数，修改管理配置不会改写任务。原有供应商撤权、模型规格限制及结果关联校验继续生效。普通图片生成请求保持原有参数行为。

前端新增管理脚本 `management/frontend/image-tools.js` 已纳入 `tools/build_management.py`。发布时用现有构建方式重新构建管理静态目录，并刷新工作台前端版本；无需修改 TOS 配置。

测试使用模拟配置、任务响应和浏览器表单，不调用供应商、不上传素材、不进行付费生成。
