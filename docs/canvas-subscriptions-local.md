# 画布状态订阅：本地实现与验收

更新：2026-09-14，第 29 批。本批没有新增 migration，依赖已有成员、租约与维护数据结构。

## 行为与边界

成员画布连接 /ws/canvases/{canvas_id}，由可信登录会话、选定空间和 canvas.read 权限确定订阅范围。每秒从 PostgreSQL 查询当前画布版本、编辑代次、维护与本成员可见的交接状态，变化时推送，未变化时每 10 秒发送心跳。每次查询重新验证身份、会话、空间与权限；撤销后关闭连接。客户端消息不能改变订阅对象或指定可信身份。

消息只含画布/空间编号、版本、代次、维护摘要、不透明状态指纹及本连接递增序号，不发送文档正文、编辑令牌或交接凭据。订阅不领取、续期或释放编辑资格。状态来自数据库，因此其他业务进程的保存和交接可被观察；本批不代表整站业务已完成多实例部署。

经典和智能画布收到变化后重新核验租约及交接状态，仅在查看模式、没有未保存内容且没有执行中的业务时读取新文档。文档应用前再次检查画布、成员页面、编辑代次及版本，丢弃切换身份/画布、开始编辑或更新版本之后迟到的响应。版本比较使用 revision，避免同一时间戳的连续保存被漏掉。

连接中断时暂停编辑并保留草稿，不释放服务器租约，也不在重连后自动恢复编辑。客户端 25 秒无有效消息关闭连接，以 1/2/4/8/10 秒间隔重连；权限拒绝不自动重试。旧连接、旧序号、版本/代次回退不得覆盖新状态。重连读取最新快照，不提供持久事件逐条重放；5 秒 HTTP 状态检查继续作为补充。

维护离线/恢复中仍可观察维护摘要，但不读取画布正文或交接明细。事件不能绕过保存凭证、维护限制或服务器版本校验。在线人数仍使用第 28 批页面/工作台心跳，订阅本身不另计人数。

## 验收

- PostgreSQL 全量 291 通过，新增 10 项/参数场景：真实 WebSocket 与独立子进程保存两类画布、重连当前快照、跨画布/空间与来源隔离、交接申请和批准、失效旧保存、四类会话/权限撤销、维护转换及租约到期。断开订阅后有效租约保持，消息不含私有凭证。
- Python 132 通过、291 云测试跳过、7 subtest 通过。前端 CJS 最终 269 通过，覆盖作用域/序号、重连及旧回调、版本回退、心跳/超时、暂停与草稿保留、清洁查看页刷新以及两类画布迟到读取保护。
- 真实浏览器使用隔离 localhost:8772 预览，经典和智能画布分别由编辑页创建/修改提示词并保存，已打开的查看页自动显示最新文字且保持只读；经典画布接管到另一页后，原页面停止编辑并提示保留草稿。没有调用生成服务，数据库任务与付费提交均为 0。
- 浏览器发现默认计时器被当作对象方法调用导致 Illegal invocation，已改为包装函数，并增加会检查调用接收者的回归用例。修复后重新加载两类页面完成上述验收。
