# 火山引擎视频费用

火山 Ark 视频任务使用返回的 `usage.completion_tokens` 核算：

`费用（元）= completion_tokens × 单价（元/百万 tokens）÷ 1,000,000`

API 设置 → 火山引擎 → 视频模型 →「规格单价」可按模型、输出分辨率、是否含视频输入配置单价。留空使用内置官方价格；填写覆盖对应规格；0 表示免费。当前页面配置在线常规推理，后端价格键同时保留 `service_tier`。第三方 Ark 兼容地址不自动套用官方价格。

内置价格核验日期为 2026-09-09，覆盖 Seedance 2.5、2.0、2.0 fast、2.0 mini，包含已公布优惠的结束时间。价格不会自动联网更新；后续官方调价需更新配置或内置价格表。来源：<https://www.volcengine.com/docs/82379/1544106>。

## 保存内容

- 任务结果保留 `raw`，并新增 `usage`、`video_info`、`cost`。
- `video_info` 保留返回的实际模型、分辨率、宽高比、时长、帧数、帧率、音频和服务档位等字段，同时单独保存请求模型、请求规格、视频输入标记、供应商及任务 ID。
- `cost` 保留用量字段、token 数、单价、价格版本和生效区间、计价时间、价格快照及整数微元金额。金额在后端以 Decimal 计算，最后一步才舍入。
- 异步任务在本地视频下载前将用量和费用写入任务 SQLite 存储。下载失败仍保留上游成功结果和成本；服务中断后的恢复使用已保存的价格和响应。
- 两套画布的生成日志和输出视频对象保留用量、规格和费用。任务数据库的保留独立于画布日志最近 5,000 条的保留范围。

## 边界

缺失或无效的 `completion_tokens`、缺失实际分辨率、没有匹配价格时，费用为 `unknown`（待核算），不会按秒回退或将缺失用量填零。明确返回 0 tokens 可核算为 0。`total_tokens` 及其他原始 usage 字段保留，但不替代 completion tokens。

旧火山按秒记录保留原始内容，展示时不再计入已核算总额。本次不自动回算历史任务；内置价格不用于核验日期之前的任务。重新生成只影响新任务的价格快照，修改单价不会改写已核算任务。

费用为用量乘适用单价的模型成本；优惠券、资源包及账户实际扣款需要另行对账。其他供应商继续使用原有计费方式。
