# 管理平台与线上协作实施记录

更新：2026-09-14。整体目标仍在实施，依据[管理平台计划](management-platform-upgrade-plan.md)和[画布协作计划](online-collaboration-upgrade-plan.md)。以下记录实际交付，不代替各阶段完整验收。

## M1+C1：成员与权限服务基础

已实现第一批后端能力：

- migration 004 追加成员、激活凭证、分站点登录会话、登录尝试、空间成员、权限目录、角色、授权关系及管理审计表；001–003 不变。
- 受控本机初始化、一次性激活、密码重置、会话退出/到期/停用撤销、成员昵称与颜色头像。密码使用 scrypt；会话及激活凭证只存哈希；同一凭证不能跨工作台/管理站点使用。
- 平台/空间权限分离、创建空间及初始管理员、成员空间分配、内置模板、自定义角色增改及停用。角色停用要求当前影响预览和明确替代/撤销方案；角色更新检查版本。
- 不以角色名称判断权限；禁止越权委派、通过重置高权限账号提权、跨空间角色绑定和移除最后有效管理员。数据库复合外键约束角色所属空间和权限作用域。
- `authorization.authorized()` 在数据库事务内保护操作；授权变更使用独占协调锁，普通受保护操作使用共享协调锁，直到提交才释放。当前首先确保撤权一致性，后续可按实测负载细化锁粒度。
- `tools/member_admin.py bootstrap --username <账号> --name <昵称>` 提供一次性 CLI 初始化，密码从终端输入。此命令只建立账号与角色，不代表业务入口已切换。

验证：`python\python.exe tools\cloud_test.py --tb=short` **65 通过**（原 52 项 + 新增 13 项）；`python\python.exe -m pytest -o pythonpath=. tests -q --tb=line` **120 通过、65 云集成跳过、7 subtest 通过**；`node --test tests/*.cjs` **158 通过**。云集成在每轮临时 schema 中应用 004 并清理。

当前边界：**M1+C1 未完成，线上入口尚未启用个人成员模式。** 新权限服务尚未挂接所有业务 API、WebSocket 或 worker，不可把服务层测试视为整站已隔离。开发库仍保留 001–003，尚未向其应用 004–005、未初始化真实管理员；启动新版 PostgreSQL 应用前须先备份并按迁移流程应用待执行 migration。原私有配置、素材和 `.local/cloud/objects` 不变。

## M1+C1：首批业务仓库空间隔离

第二批增加 task-local 的空间上下文，改造画布、共享文档和历史仓库的读写过滤及 INSERT 归属。文档 revision 缓存键包含空间，历史分页游标绑定空间；跨空间画布冲突响应不返回其他空间正文。成员模式下未显式绑定空间的存储调用拒绝执行。

新增 5 项实库测试验证画布读取/列表/冲突、同键文档版本与删除、历史游标与删除、并发空间上下文及异常退出恢复。最新验证：云集成 **70 通过**；Python **120 通过、70 云集成跳过、7 subtest 通过**。本批未修改前端，沿用上一批 **158 项 CJS 通过**的证据。

空间上下文本身不授予访问权限。当前共享认证仍未切换，素材、任务、账本和网络入口尚未全部接入，不能据此启用线上多空间；也不要单独配置 AUTH_MODE=members 作为完成切换。旧历史分页游标需刷新首屏重新获取。

## M1+C1：素材、任务与账本空间隔离

第三批已接入素材别名/发布、分片上传、任务输入检查、任务持久记录、结果恢复和费用账本：

- 追加 migration 005，为现有上传回填所属空间并将上传幂等键改成空间内唯一；旧对象 key/version 保持原值。独立旧 schema 升级用例验证回填保留原件身份。
- 新对象与 staging 使用空间前缀；素材 ID、别名、上传查询及取消受空间限制。签名 GET/PUT 包含空间并参加 HMAC，伪造空间不可获得素材或写入分片。受控全局清理 CLI 显式遍历空间，单空间清理保留本空间范围。
- 任务查询、输入素材、重复任务 ID、画布关联和执行租约校验绑定空间；跨空间创建或更新不能取得另一空间任务内容。
- worker 以持久任务记录恢复空间，包括心跳线程和异步媒体处理；空间停用不领取新的排队生成任务，已提交任务的查询/结果恢复仍能继续。完整平台/空间维护状态机和提交前权限复验仍属后续工作。
- 五张费用兼容表按空间查询与写入，去重/合并事务按空间协调；同名历史画布和日志在不同空间保持各自金额、版本和冲突记录，原价格与金额不重算。

新增 7 项专项实库测试，覆盖双空间对象/别名、签名上传与清理、账本隔离、任务越界、真实 worker 使用模拟供应商完成结果/历史/费用写回、归档空间任务领取及升级回填。最新结果：云集成 **77 通过**；Python **120 通过、77 云集成跳过、7 subtest 通过**；无前端代码变更，沿用此前 158 项 CJS 证据。数据库与对象操作仍限于自动创建的本地隔离验收范围。

M1+C1 仍未完成：个人认证及资源权限尚未挂接全部 HTTP/实时入口，不能把这些仓库和 worker 测试视为整站多空间验收；管理平台及两种画布联调继续执行。
