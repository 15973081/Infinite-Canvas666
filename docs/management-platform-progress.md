已实现第一批后端能力：

- 受控本机初始化、一次性激活、密码重置、会话退出/到期/停用撤销、成员昵称与颜色头像。密码使用 scrypt；会话及激活凭证只存哈希；同一凭证不能跨工作台/管理站点使用。
- 平台/空间权限分离、创建空间及初始管理员、成员空间分配、内置模板、自定义角色增改及停用。角色停用要求当前影响预览和明确替代/撤销方案；角色更新检查版本。

- `tools/member_admin.py bootstrap --username <账号> --name <昵称>` 提供一次性 CLI 初始化，密码从终端输入。此命令只建立账号与角色，不代表业务入口已切换。

## M1+C1：素材、任务与账本空间隔离

第三批已接入素材别名/发布、分片上传、任务输入检查、任务持久记录、结果恢复和费用账本：

- 追加 migration 005，为现有上传回填所属空间并将上传幂等键改成空间内唯一；旧对象 key/version 保持原值。独立旧 schema 升级用例验证回填保留原件身份。
- 新对象与 staging 使用空间前缀；素材 ID、别名、上传查询及取消受空间限制。签名 GET/PUT 包含空间并参加 HMAC，伪造空间不可获得素材或写入分片。受控全局清理 CLI 显式遍历空间，单空间清理保留本空间范围。
- 任务查询、输入素材、重复任务 ID、画布关联和执行租约校验绑定空间；跨空间创建或更新不能取得另一空间任务内容。
- worker 以持久任务记录恢复空间，包括心跳线程和异步媒体处理；空间停用不领取新的排队生成任务，已提交任务的查询/结果恢复仍能继续。完整平台/空间维护状态机和提交前权限复验仍属后续工作。
- 五张费用兼容表按空间查询与写入，去重/合并事务按空间协调；同名历史画布和日志在不同空间保持各自金额、版本和冲突记录，原价格与金额不重算。

新增 7 项专项实库测试，覆盖双空间对象/别名、签名上传与清理、账本隔离、任务越界、真实 worker 使用模拟供应商完成结果/历史/费用写回、归档空间任务领取及升级回填。最新结果：云集成 **77 通过**；Python **120 通过、77 云集成跳过、7 subtest 通过**；无前端代码变更，沿用此前 158 项 CJS 证据。数据库与对象操作仍限于自动创建的本地隔离验收范围。

M1+C1 仍未完成：个人认证及资源权限尚未挂接全部 HTTP/实时入口，不能把这些仓库和 worker 测试视为整站多空间验收；管理平台及两种画布联调继续执行。

## M1+C1：成员 HTTP 入口与空间实时状态

第四批已将成员模式接入现有 ASGI 应用并完成隔离实库/HTTP 验证：

- AUTH_MODE=members 使用 PostgreSQL 成员登录、独立工作台 Cookie、激活、退出、资料与空间列表 API。共享 Cookie、共享密码与 Basic 不参与成员认证；管理站点 audience 的会话也不能作为工作台会话使用。
- 数据请求明确指定 X-Workspace-ID 或 workspace 查询参数；冲突、缺失及未分配空间均拒绝，不自动落入 default。请求许可通过 ContextVar 传入同步/异步仓库，每次新数据库事务复验成员/空间/权限并与撤权事务协调。
- 对话身份只取服务端成员，忽略前端 X-User-ID；对话列表补齐空间过滤。供应商摘要剔除密钥槽、服务地址和本机连接配置；旧密钥读取和管理入口不向成员工作台开放。
- 成员 WebSocket 使用空间状态流，不进入旧全局广播；逐次发送和心跳复验会话/空间权限，撤权关闭连接。队列按空间及可信任务发起人计算，普通状态不展示 IP。
- migration 006 追加任务 requested_by，发起人从认证上下文落库，旧任务不猜测归属。worker 在新的生成执行前复验成员状态及生成/供应商使用权限；已提交任务的结果恢复继续保留。
- 内部供应商结果检查点不可通过素材预览、签名或任务输入接口当作用户素材读取。

新增 8 项测试，最新：云集成 **85 通过**；Python **120 通过、85 云集成跳过、7 subtest 通过**。全量路由静态盘点保存在 .local/cloud/acceptance/member-route-inventory.json，共 146 个原路由，记录已分类、待迁移、本地上传库、旧管理和旧画布锁入口；静态分类不是端到端验收，公开/签名及成员账号入口另行处理。

**此阶段仍不能作为完整线上切换。** 开发服务尚未启用成员模式。前端空间选择与会话接入、局域网本地上传库、ComfyUI/全局工作流、直接生成/聊天/注册等尚未完成迁移的接口暂时拒绝成员访问，需继续按原计划迁移并验收；不把关闭功能作为最终完成。画布锁旧入口等待 C2 新租约协议替换，旧管理入口等待 M2 独立管理平台接入。完整维护策略、批次内各付费提交边界、历史身份映射与恢复切换仍在后续范围内。

## M2：独立管理入口与成员/空间/角色页面

成员页支持创建、停用/启用、重置激活、撤销会话；空间页支持按初始管理员账号创建、归档/启用、分配成员；角色页支持权限目录、自定义增改、版本检查、影响预览和停用替代。成员授权采用 expected_version 防止旧页面覆盖新授权。列表、精确账号查找和审计查询在事务中鉴权；空间管理员不能浏览全局成员或其他空间管理数据。依赖故障返回脱敏 503，前端有登录失效、无权限和重试入口。
