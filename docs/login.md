# 登录与访问账号

现在本地版和云端版均使用独立登录页：打开站点后，未登录的请求会进入 /login。原画布、素材和供应商配置仍属于同一个共享工作区。

## 本地首次使用

1. 启动服务，在服务器本机访问 http://localhost:6003（或实际端口）。
2. 设置访问账号与至少 12 位密码，确认后进入画布。初始化仅允许来自本机、使用 localhost/回环地址访问的请求。
3. 后续使用该账号登录；“保持登录 30 天”设置持久会话，不勾选时服务端会话最长 12 小时。
4. 主界面侧栏“退出登录”会先调用画布保存逻辑，保存失败时保留页面。登录过期会提供新标签页登录入口，不强制刷新编辑中的画布。

本地账号使用 scrypt 加盐哈希；会话令牌保存在 HttpOnly、SameSite=Strict Cookie 中，服务端仅保存令牌哈希。退出撤销当前会话；更改账号配置后旧会话失效。HTTPS 部署自动使用 Secure Cookie。每个来源地址 5 分钟内最多允许 10 次失败登录。

## 云端或预先配置账号

沿用 CLOUD_ACCESS_USER 和 CLOUD_ACCESS_PASSWORD；PUBLIC_BASE_URL 设置为实际站点源地址（例如 https://canvas.example.com）。云端不开放首次注册，必须配置访问凭证。这些变量也可以在本地模式下使用，优先于初始化账号。通过 STORAGE_ENV_FILE 加载配置，或在启动服务前设置进程环境变量。

旧云端脚本的 HTTP Basic 凭证仍可使用；浏览器改用登录页和 Cookie，不再弹出原生认证框。已有签名媒体链接继续按原有签名与有效期校验。

## 文件与恢复

账号、会话和登录限流数据默认存放在 .local/auth.sqlite3（已被版本控制忽略）。AUTH_DB_PATH 可以指定其他持久路径；生产环境应限制该文件的操作系统访问权限，并为它配置持久卷与备份。应用内的上传/静态资源路由不提供此文件。

忘记本地密码时，服务器管理员可在停止服务后执行：

    python/python.exe tools/reset_login.py

该命令在终端交互输入新账号和密码，不输出密码或哈希，重置后撤销全部本地会话。若设置了 CLOUD_ACCESS_PASSWORD，应在对应环境配置中修改并重启服务。

当前会话存储支持同一主机、同一数据库路径的多个进程。多主机部署应先迁移为共享会话存储，不能每台使用独立文件。当前版本提供的是共享工作区入口保护，不包含独立用户空间、邮箱找回或团队权限。
