# 素材库成员图片显示修复

2026-09-14，第 33 批。

## 问题

第 32 批修复了双画布图片地址，但素材库管理仍直接输出未绑定空间的 URL。列表和右侧详情使用的 /api/media-preview，以及预览失败后的原图回退，都缺少当前成员/空间；因此原素材存在也会显示破图。

## 修复范围

asset-manager.js 统一调用既有 MemberMediaUrl：图片资产、画布资产和复用缩略图的列表、右侧详情、图片/视频灯箱、打开原图链接、单文件下载及图片加载失败回退。保存在资产记录、复制引用和画布中的稳定 URL 保持原值；仅在渲染/导航时附加当前成员与空间。

视频素材只有存在真正预览地址时才用图片缩略图，API content 视频地址加查询参数后仍使用 video 元素。暂停会话时不打开空链接或启动下载。共享文件夹/本地素材目录的成员入口迁移仍未完成，本批复用显示辅助函数不代表开放这些后端接口。

- 全量 CJS **293 通过**，日志 .local/cloud/acceptance/asset-manager-media-cjs.log。本批没有 Python、数据库或签名协议修改；沿用第 32 批 PostgreSQL 313、Python 134 的基线，不声称重新执行。
