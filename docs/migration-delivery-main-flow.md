## 持久服务入口

新增 tools/delivery_service.py，按显式配置运行单个工作台、管理或 worker。它核对数据库名及 schema，仅检查已有数据库，不初始化、不迁移、不删除数据。管理前端从当前源码构建；三个服务分别运行，工作台禁用内嵌 worker。

候选配置在 .local/cloud/delivery/prep-1789419296365/candidate/service.env。供应商解密密钥通过 PROVIDER_SECRET_KEY_FILE 引用原备份密钥，不生成替代密钥。

从项目根目录执行（以下为工作台示例）：

```powershell
.\python\python.exe tools/delivery_service.py workbench --env .local/cloud/delivery/prep-1789419296365/candidate/service.env --database canvas_delivery_1789419420170 --schema workbench_ui_343d3aa95f4c494b9a6758409d6e7a44 --port 8878 --stop-file .local/cloud/delivery/prep-1789419296365/candidate/workbench.stop
```

管理进程使用 management、端口 8880 和 management.stop；worker 使用 worker、无需端口和 worker.stop。本次第二账号辅助工作台运行于 localhost:8879，进程覆盖 PUBLIC_BASE_URL=http://localhost:8879，使用 second.stop。

要停止某个进程，创建它的停止文件；确认该进程退出后再删除该文件并重启。入口拒绝在已有停止文件时启动，不根据陈旧 PID 文件杀进程。系统终端外启动时应采用隐藏后台窗口。
