# 在线作品收件箱

在线生成按图片建立独立作品记录；经典/智能画布内生成继续由画布管理。保留现有生成 API、任务 ID、供应商执行与费用契约。

## 管理流程

- **未整理**：新生成图片，支持名称、文件夹、标签、搜索、模型和成员筛选、分页及多选。
- **已保留**：明确长期保留的作品。保存到素材库时，在同一个数据库事务中标记本人的作品为已保留；托管图片只增加库引用，不复制文件。
- **回收站**：保留原状态和原图，可以恢复。移入回收站不释放空间。
- **清理待完成**：已经通过引用核对并开始物理删除，无法恢复；对象存储或暂存清理失败可以重试。
- **已彻底删除**：保留最小作品墓碑，清除作品媒体快照；按对象版本删除原件、关联预览。最后一张在线任务结果被删除后，清理该任务已不再需要的私有结果检查点和图片回执。

未启用自动过期清理或配额拦截；旧作品不会被自动删除。文件替换采用新的不可变文件编号，不能覆盖被其他页面引用的原件。

引用状态筛选支持全部、仅看未引用、仅看已引用，与搜索、成员、模型、文件夹和分页组合。服务器在分页之前核对已保存的画布（含回收站）、素材库、备份、任务输入、活动任务和其他作品；同时检查关联缩略图。作品自身的历史图片和已完成、无租约的在线任务输出只属于来源，不算额外引用。其他作品共用同一文件仍算引用。外部链接、未映射或未就绪的资产状态未知，不列入未引用。筛选为只读快照，彻底删除时仍重新校验所有引用；未保存的浏览器编辑无法参与判断。不需要数据库迁移。

普通成员需 `asset.manage` 且是作品生成者才能修改；拥有空间成员管理权限的空间管理员可以管理历史归属不明的作品。读取受 `asset.read` 和空间成员关系约束。作者来自服务器任务 `requested_by`，不接受浏览器传入作者。

## 删除保护

每次彻底删除重新检查所有画布（包括回收站）、素材库、保留备份、其他作品及任务引用。`canvas_assets` 索引不作为唯一依据。

只释放本次所选作品关联的、已完成且无有效执行租约的在线图片任务输出引用。任务请求、输入素材、画布任务和 `needs_review` 等可恢复任务仍受保护。拒绝删除会回滚本次输出释放和清理状态。

历史任务保留供应商、模型、请求指纹、成员归属、状态和费用；结果中的图片移除，并写入 `media_expired`、`expired_image_count`。费用账本及其历史输出说明不被改写，也不会触发重新计费。

通过引用核对后先提交资产 `deleting` 状态，阻止并发重新引用；随后删除固定对象版本。失败保留可重试状态，不删除整个对象键、目录或存储桶。外部链接只删除作品记录，不能删除远程站点文件。

## 数据库及迁移

`027_online_inbox.sql` 增加 `online_works` 及空间、状态、作者、资产索引。按现有历史图片拆分记录，复用 `assets` 编号。迁移也找回“历史被删但已完成在线任务还保留结果”的文件；没有可靠作者的作品明确标注历史归属不明。带画布 ID 的历史孤儿任务排除在在线收件箱之外。

`028_online_inbox_cloud_refs.sql` 补齐 `/assets/cloud/<asset-id>/<name>` 地址的旧记录映射，确保这些作品正确显示大小、参与文件引用检查和物理清理。仅关联当前空间的就绪资产，不移动媒体。

原历史资料不丢弃，媒体不搬运、不复制。新历史持久化时自动登记作品，重复保存同一历史位置不会重复登记。工作空间共享导出包含收件箱，旧版共享导出仍可以校验。

本地发布前备份数据库，在明确的数据库/schema 上运行：

```powershell
.\python\python.exe tools/cloud_storage.py init-db --env <现有环境文件>
```

随后重启工作台、管理平台和 worker。不能修改已经应用过的迁移文件。

## 验证

```powershell
.\python\python.exe tools/cloud_test.py -k "inbox or online_results or asset_purge"
```

浏览器检查使用已安装的 Playwright（可通过 `NODE_PATH` 指定其安装目录），对隔离 PostgreSQL/schema 和真实 HTTP 服务执行页面 CRUD、素材库导入、深浅主题、手机宽度和 Esc 关闭。测试只删除本次测试对象。截图保存在 `.local/online-inbox/`。缺少 Playwright 时浏览器用例明确跳过，后端用例仍执行。
