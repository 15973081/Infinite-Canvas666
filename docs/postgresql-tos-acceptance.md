## 已明确的边界

- TOS 是本地对象接口模拟。真实 TOS 权限、网络、配额、跨桶恢复版本重映射、供应商拉取签名素材，以及生产负载需实际部署后另行联调。
- 供应商响应尚未持久化前的丢失不能凭空恢复；图片批次中途的未知付费状态不会自动整批重发。外部 API 不具备由本应用保证的恰好一次语义。
- 共享工作区保留一个 Web 进程；实时编辑锁和部分旧队列仍是进程内状态。素材库/目录保留设计允许的单文档树形协议，单个对话正文仍按文档读取。兼容历史数组接口最多 5000 条，新图库使用分页接口。
- 迁移要求停写的一致备份；JSON/SQLite/文件不会自动做持续增量合并。未提供浏览器 `localStorage.json` 仅说明服务器备份中没有该导出，不能推断浏览器没有待保留内容；提供导出也需人工选择保留项。
- 真实原数据切换、正式上线、异地备份调度和多实例扩容未执行，不包含在此次 `.local` 本地验收中。
