# 在线成员名单：本地实现与验收

更新：2026-09-14，第 28 批。追加 migration 016，不修改既有 migration。

## 行为与数据来源

工作台 /ws/stats 的连接在线记录进入 PostgreSQL member_presence_sockets，服务端为每条连接生成随机编号，绑定真实成员、登录会话、空间和身份版本。5 秒状态推送续期，同空间跨进程查询可见；客户端传入的 client_id 不决定归属。一个连接结束只清理自身记录，进程崩溃或数据库故障由 35 秒时效兜底，不释放编辑租约。超过一天的 socket 记录在后续在线心跳中清理，页面诊断历史不删除。

空间名单合并有效 socket 与已有页面心跳，按成员去重。当前画布名单只使用该画布的页面心跳，双画布共用 10 秒上报和协作栏，无需为画布名单新增第三套页面身份。返回成员 ID、昵称、头像、是否本人和查看/编辑状态；不返回 IP、登录会话 ID、页面 ID、编辑凭证、未保存内容或其他空间的信息。

名单查询在权限事务内执行，同时复验请求人和每个被展示成员的会话、状态、身份版本、空间成员资格和 canvas.read 权限。旧身份版本的记录立即排除，重新验证后的新心跳才可出现；角色变更后失去 canvas.edit 的成员不能继续显示旧编辑资格。改名从成员表实时读取，同名成员以短编号区分。

编辑状态来自当前有效数据库租约及 canvas.edit/canvas.read 授权。名单不能授权写入，成员离线不代表租约已释放；编辑者尚有有效租约但无在线心跳时，名单不列为在线，原有占用提示仍按租约展示。同账号不同画布分别计算编辑/查看状态。

双画布的“本画布在线 N 人”可展开，展示昵称、成员短编号、本人标记及编辑/查看状态。名字以 textContent 插入。乱序心跳响应、切换账号/空间后的旧响应不得覆盖当前名单；获取失败、会话暂停或超过 35 秒未刷新时隐藏旧名单，显示暂不可用。名单自身不续租或恢复编辑。

## 恢复与部署

空库恢复事务新增清空 member_presence_sockets。旧页面诊断记录继续保留，但旧登录会话和身份版本已失效，不计入新登录后的在线人数。真实恢复测试包含 socket 和页面记录，并验证恢复后仍为零在线。

本批仅在隔离本地 schema 验收，没有对用户环境应用 migration 或重启服务。当前用户预览待应用 013–016，开发 schema 待应用 004–016；启用前需沿既定备份、维护和迁移流程部署。旧后端未返回名单时，新静态客户端显示名单暂不可用。

## 保留的未完成范围

此次证明在线名单能跨进程读取，不等于整站已支持业务多实例。画布事件订阅和广播、查看者文档同步、后台结果加入、完整断线/休眠/交接/维护故障矩阵，以及实际用户数据切换仍按原计划继续。在线状态属于有时效的观察，不是所有浏览器都已保存或可停库的证明。
