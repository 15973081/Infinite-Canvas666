# Smart 选择与 composer 分轮边界

日期：2026-10-04；划界基线：`d3c5576`。本文件是独立划界记录，不修改原始盘点与历史复盘快照。

## 所有权与独立生命周期

| 数据/会话 | 归属 | 操作与约束 |
| --- | --- | --- |
| 主选择、多选、图片子项选择 | workspace；后续单独收拢 | 选择/清空/恢复/删除通知需要完整命令；保留引用预览的临时选择恢复和任务输出选择规则 |
| composer 当前目标、切换标记、显示基线 | workspace 的 composer 功能 | 先收拢此边界；切换前保存旧草稿，再加载新目标和设置；相同目标刷新不能吸收未保存编辑 |
| 草稿 HTML/文本、节点运行设置 | 原节点/文档内容 | 不复制一份草稿；输入 DOM 是当前编辑值，baseline 只是判断用户改动的派生快照 |
| 当前 settings、默认设置和最近设置 | 现有配置/工作区与生成适配流程 | 本轮不替换数据结构；保留节点设置继承、UI 显示规范化和已有持久化调用 |
| 已提交生成输入、任务恢复、保存和撤销 | 原 execution/document/session | 保留任务输入投影与快照、权限、写回保护、保存/撤销顺序；只允许将原 composer 字段写入改为等义 UI 通知 |

`activeComposerSubject` 目前不是生成任务快照：workspace 设置当前节点；document 的撤销/导入与 execution 的收尾会清空它。`lastComposerNodeId` 控制草稿/设置切换，不能单独改名后交给调用方继续拼接。`smartComposerBaseline` 防止 UI 默认值和渲染规范化回写运行中任务输入，必须连同对应方法一起移交。

## 分轮实施

1. **composer 输入目标会话**：将上述三个绑定移入 `createSmartComposer()`；完整刷新/切换、草稿同步、目标查询、设置持久化、文档替换通知和任务 UI 收尾由所属功能提供。外部不读取/写入会话字段。保留旧函数名为薄委托，任务输入投影继续通过同名查询使用已有差异结果。
2. **工作区选择命令**：单独核对主选择、多选和子项选择；按节点点击、框选、引用临时预览、文档恢复及任务输出的差异逐类替换。选择恢复不能被通用“选择节点”额外保存草稿或重排 UI；不把节点/图片数据拷贝进状态对象。
3. **输入应用协作验收**：核对模板/预设、媒体编辑及动态设置应用是否仍需拼接目标字段，收敛必要的完整操作；草稿内容继续归节点，运行中任务快照继续归执行模块。边界清楚后收尾，不以隐藏全部 settings 读取或清零全局变量为目标。

各轮单独验证与交付。当前第一轮不封装全部选择、不改 composer 布局或全部输入监听、不修改运行任务、保存、锁、撤销算法。

## 第一轮行为验收

- 冻结标量快照；三个会话字段无外部读写；构造不访问 DOM。
- A→B→A 保留各自富文本/媒体标记和设置；无编辑的渲染刷新不新增草稿/设置写入；有编辑的刷新保留差异。
- 清选择、非图片节点选择、静默级联、任务输出选择保留各自关闭/清空/设置恢复行为与保存次数。
- 同 ID 节点对象或画布替换不能把旧输入投影到新对象；文档替换走显式通知。
- 关闭、缓存页面暂停/返回和永久销毁清理自身会话；不删除共享输入/工作区监听。
- 原有运行中任务输入绑定、任务恢复、模型规范化、只读权限、保存次数和局部刷新基线保持一致。

后续渲染/几何缓存、管理 UI 和总体验收继续按总计划推进；本文件不宣称这些阶段已经完成。
