# 画布后台同步与请求频率

这些接口由后台同步触发，与鼠标操作无关。多开标签页会按页面叠加请求量。

| 请求 | 用途 | 调整后的自动频率 |
| --- | --- | --- |
| `edit-lease/renew` | 保持当前页面的编辑资格 | 按服务端心跳，默认 10 秒；查看模式不发送 |
| `edit-lease/transfers` | 查询编辑者、交接申请和修订 | 实时连接正常时 60 秒兜底；断线时查看模式 15 秒；有交接申请时 5 秒 |
| `page-state` | 上报页面在线、是否有未保存内容 | 20 秒；内容变更、页面关闭时立即上报 |
| `task-results` | 同步可恢复的生成结果 | 无进行中任务时 60 秒；进行中任务 5 秒；页面隐藏时暂停 |
| `meta` | 旧版画布的修订检查 | 成员画布使用统一同步；旧模式 30 秒兜底，隐藏时暂停 |
| `frontend/version` | 检测前端发布更新 | 顶层页面每 5 分钟；聚焦或恢复可见时检查，30 秒内去重；子 iframe 不单独轮询 |

WebSocket 收到实际状态变化时立即查询交接状态并核对任务结果。正常续期只延长编辑锁期限，不再改变订阅摘要、触发额外 HTTP 查询。编辑者、交接、锁到期、维护模式和文档修订变化仍会通知。

已完成或失败的任务不再保持每 5 秒查询；完成状态也不会因低频核对被错误显示为断线。恢复可见或网络连接时会重新核对任务。

隐藏页面仍保留编辑锁续期和在线状态上报。页面状态在服务端 35 秒后会视为过期，不能把它任意延长到一分钟。浏览器冻结页面或断网可能导致锁到期，恢复后仍需重新确认编辑资格。

总传输量还包括图片、视频、模型和运行库。评估轮询流量应在开发者工具中单独筛选上述接口；不能将单个大资源的体积归因于这些小接口。

前端修改需要刷新页面载入。订阅摘要的后端修改需要重启服务进程后生效。
