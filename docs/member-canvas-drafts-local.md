# 成员画布草稿恢复与清理

2026-09-14，C3 第十一批。整体线上迁移仍在进行。

## 本批行为

- 两种画布的本地草稿列表增加明确恢复和单条删除。列表仅查询当前成员、空间、画布的记录，区分本页、其他页面和恢复前留存；列表打开后账号或空间改变，操作会拒绝。
- 恢复前必须先通过正常开始编辑流程取得本页私有凭证。恢复操作与保存串行，临时停止新编辑，并使用私有凭证请求服务器续租以复验登录、权限、维护、代次及当前 revision。草稿基准版本必须等于本页已确认版本及此次服务器返回版本；不一致或未知版本不应用内容，不自动合并或重试旧保存。
- 恢复需确认；本页有未保存更改时先暂存、导出。本次恢复只在页面应用节点、连线、标题/图标及智能画布设置，标记未保存；检查后可点击保存，后续编辑仍遵循原自动保存机制。草稿自身不提供授权，也不保存租约 token。
- 恢复保留服务器画布身份、revision、创建时间和费用日志，清除恢复节点的待执行任务状态，不重新启动生成。当前页仍有在途保存、生成或级联执行时拒绝恢复，防止旧回调混入新图。尚未完成任务结果的独立导入，原草稿导出仍保留完整内容。
- 原草稿继续保留；若恢复的是本页记录，先复制为独立留存记录，再更新本页暂存，避免后续暂存覆盖恢复源。暂存文档在调用时深拷贝，增加记录 ID 和基准代次，并使用挂载时的成员/空间，避免异步操作改绑到新账号。
- 删除需要确认，在同一个 IndexedDB 写事务内重新读取并比较完整记录，另一页面更新过的记录不能误删。不清理本页仍有未保存内容的草稿，不设静默过期删除。无编辑资格的未保存页面可确认“导出并离开”，不再永久卡在返回入口，也不宣称保存到了服务器。
- 修复新建经典画布后未安装成员编辑控件的入口遗漏；成员模式远端刷新不再根据本地 Comfy 工作流缺失而裁剪服务器节点。
