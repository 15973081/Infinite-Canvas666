# 工作区渲染与几何缓存边界

日期：2026-10-05。此记录限定总计划第四阶段，不扩大到选择、文档保存、历史、任务协调或通用渲染框架。

Classic 的连线 Map 由 workspace 更新、入口直接清空；几何队列的四个绑定、视口刷新计时器、输入列表 WeakMap 均声明在入口，使用集中于 workspace。Smart 的计算索引、缩略图滚动 WeakMap、几何队列、视口刷新计时器、节点 HTML WeakMap 和连线展示签名同样属于工作区派生数据；execution 额外直接读取计算索引。

两套画布各由自己的工作区视图功能持有缓存和调度，不合并实现。外部保留原刷新函数作为操作委托，入口仅初始化、绑定及通知文档/画布失效。Classic 的退出直接清 Map 改为重置入口；Smart execution 通过节点及入边查询使用临时索引，不取得可写 Map 或上下文别名。

保留几何队列的范围合并、全范围优先、第二帧修正以及 Classic 拖动结束即时 flush；Smart 直接连线刷新继续取消旧修正。计算上下文只在同步调用内存在，嵌套复用，finally 释放；不成为生成任务快照。节点 HTML/对象身份、滚动位置、输入列表签名、连线 DOM 复用与原算法保持不变。

帧与视口计时器记录发起时的画布 ID、节点数组及代次。切换或替换后旧回调不作用于新文档；显式重置取消工作并清派生缓存。相同画布内过滤/复制节点数组只取消旧队列，继续按节点对象、DOM 和签名复用有效缓存，避免删除时重建无关连线。缓存离开暂停调度、保留当前 DOM，返回只补视图校正，不新增保存；永久离开解绑自身监听并清理引用。已提交任务仍通过原数据查询完成，不因 UI 销毁中止。

验证重点：局部/全局范围合并与 flush、120 次请求帧合并、2000 节点不变 DOM 复用、100 次输入更新保留列表、连线增删/端点重绑、缩略图滚动和虚拟化保护、异常后计算索引释放，以及真实浏览器的文档替换、缓存返回与销毁。新增验收只针对新的所有权和清理边界，保留已有性能与保存断言。

工作区其他手势、选择与媒体自身资源不由缓存功能清理。Classic 已挂在图片 DOM 上的媒体挂起恢复 WeakMap 属于原虚拟化资源逻辑，是否纳入应以实际调用边界为准；不为数量减少改变媒体行为。该记录是实施边界，不宣称第四阶段已完成。
