# 2026-10-08 Skill 引用容量升级公告与说明

AI 对话中所选 Skill 正文及文本参考文件的总引用上限从 48,000 字符提高到 **1,000,000 字符**。已安装固定版本的正文和文本参考文件会完整保留，完整保存到本轮消息快照并传给模型，不截断、不自动精简。

等于上限可发送；超过上限整次拒绝，显示实际字符数和上限。例如：

> 所选技能正文及参考文件共 1,000,001 字符，超过本次引用上限 1,000,000 字符，请减少引用数量。

引用计数包含正文、文本参考文件、参考文件路径和拼接分隔文字，不含聊天提示包装。实际字符数使用 Python 字符串长度计算，不按 UTF-8 字节数计算。

每次最多引用 **6 个 Skill**。单个 Skill 导入仍为最大 2 MiB，正文及可读参考文件合计最多 120,000 字符；因此正常导入的 6 个 Skill 内容合计最多 720,000 字符，另加路径及分隔文字。本次调整不提高单包导入限制。

仅允许引用当前空间已安装且发送成员已启用的 Skill。未安装或未启用时，发送被拒绝，不新增对话历史或请求模型。

此次升级不修改已有 Skill、历史对话、画布、素材或 TOS 文件，不需要生产数据库迁移。Skill 仍仅为文字参考，包内脚本不会执行，也不会授予操作平台的权限。

模型供应商自身的上下文容量限制仍适用。平台不会通过截断或自动精简来适配模型；较长引用可能增加输入用量及响应时间。

升级公告及说明同时展示在平台的 **Skill 库** 页面，展开标题即可查看。
