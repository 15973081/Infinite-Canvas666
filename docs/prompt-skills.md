# 提示词 Skill 库

资源侧栏新增独立 Skill 库。Skill 仅为 GPT 对话提供用户选择的文字参考，不接入画布执行器，不向模型提供平台工具，也不执行包内脚本。

## 使用

1. 可先下载页面提供的模板；点击选择文件或拖入带 YAML `name`、`description` 的 Markdown 文档，或含单个 `SKILL.md` 的 ZIP。每次一个文件，最大 2 MiB；文件夹、多文件、空文件和其他格式会提示重新选择。
2. 预览正文并选择“仅本空间”或“跨空间共享”。上传者取自登录成员，客户端和包内作者字段不能冒充上传者。
3. 导入自动安装到来源空间；其他空间从共享目录安装固定版本。
4. 每名成员独立勾选启用。在 GPT 中输入 `@` 或点击 `@` 按钮，搜索并选择本次要用的 Skill。
5. 每次最多选择 6 个，正文及参考总上下文最多 1000000 字符，保留完整内容，不自动截断。超限提示显示实际长度和上限。发送成功后清空本次选择，失败保留输入和选择。

拖入时显示高亮；读取校验与上传安装使用阶段提示和不定进度条，不显示估算百分比。校验失败可重新校验或换文件；安装失败保留文件与可见范围以便重试。上传安装期间禁止重复提交及关闭弹窗；离开整个页面仍会中断前端等待，不代表服务器操作已取消。拖拽和文件选择沿用同一权限及预览流程，不新增接口或数据库字段。

## 格式与边界

- 包最大 2 MiB；ZIP 最多 128 个条目、解压总量最多 16 MiB。不解压到磁盘，拒绝路径穿越、绝对路径、链接、加密 ZIP 和重复路径。
- 支持 UTF-8 Markdown，及 `references/`、`assets/` 下的 md/txt/json/yaml/yml/csv 文本；正文和可读文件总计最多 120000 字符。
- 脚本、`allowed-tools` 和非文本文件不会生效，预览会提示。原包保留在不可执行的数据库记录中。
- 仅支持本地文件导入，尚不提供 GitHub URL 安装。Skill 不自动调用，也不因勾选就全部注入对话。

## 权限与跨空间语义

复用现有权限：浏览和个人启用需要 `asset.read`；导入需要 `asset.upload` 和 `asset.manage`；空间安装、卸载需要 `asset.manage`。卸载限安装人或空间角色管理员；发布可见范围调整及撤下限来源空间上传者或具备当前空间管理权限的平台管理员。

共享为显式发布。服务器直接验证共享记录，始终保持请求 workspace，不通过切换 workspace 读取其他空间业务数据。取消共享或撤下后不能新安装；已安装版本保留，相当于其他空间已取得的固定副本。卸载仅删除当前空间安装及其成员启用偏好，不删除别的空间副本或历史对话。

## 数据库

新增迁移 `025_prompt_skills.sql`，包括目录、不可变版本、空间安装和成员偏好四张表。消息的 `skill_refs` 保存 ID、固定版本、摘要和本次文字快照；旧对话、画布和任务无需数据迁移。

为限制数据库体积，当前包限定为 2 MiB 的提示词技能；原包与可读内容保存在 PostgreSQL，随现有全库备份保存。空间导出包含已安装技能的文字快照 `skill_library`，不导出全局目录、其他空间未安装的技能或成员个人偏好。现有工作区“素材占用”统计仍只统计媒体，不代表整个数据库占用。

部署先运行：

```powershell
.\python\python.exe tools/cloud_storage.py init-db --env <当前部署环境文件>
```

然后重启工作台。迁移是新增表，已执行的旧迁移不得修改。非 PostgreSQL 部署返回明确的 Skill 存储不可用提示，普通聊天仍可使用。

