# Classic 选择入口端口集中读取：最后一轮交付

诊断已独立提交为 `84af2b6`，生产基线为 `2ca5dc9`。本轮按用户明确授权，仅完成 Classic 选择呈现时的端口读取顺序调整；完成验收与独立提交后，状态／模块边界整理和这一轮性能改动正式收尾，不自动扩展新任务。

## 修改范围

生产文件仅为 `static/js/canvas/classic/canvas-workspace.js`，7 行新增、2 行修改：

- `refreshSelectionVisuals()` 调用 workspace 所有者的 `refreshSelectionLinks()`。
- 私有 `renderLinksImpl()` 仍使用本次构建的 nodeById 和 points；选择入口先读取每个唯一当前端口，再进入原连线协调循环。
- 其他 `renderLinks()` 调用保持原有按需读取顺序；新增入口经过原 `view()` 的文档、暂停和销毁检查。

没有新增跨事件端点缓存、全局状态、监听或队列。每次选择刷新都重新读取真实端口或占位尺寸 fallback，原路径算法、按钮坐标、连线增删／换端点、缓存控件修复、临时线和刀切维护均保留。CSS、Smart、保存、权限、撤销和任务逻辑无内容修改；两个既有 Classic 文件的换行差异未纳入本轮提交。

## 行为验证

新增 `tests/classic-selection-links.browser.cjs` 的 6 项真实页面回归，连同既有框选、workspace 缓存和几何调度回归共 **31 项通过**：

- 从可观察的 DOM 操作核对选择入口先读取所有唯一当前端口，再写入路径；普通 dirty-node 入口保留原顺序。
- 非空／空选择、悬停按钮、path / hit path 与删除按钮中心符合实时端口；连线和节点 DOM 保持。
- 节点尺寸、坐标、端口 top 和 viewport 改变后立即取得新几何；未发送布局通知的端口变化也正确，避免跨事件坐标复用。
- 连线新增、删除、改端点及按钮脱离 DOM 后仍执行原协调；临时线、刀切轨迹维持与清除正常。
- 无端口占位使用 fallback，进入视口恢复后使用真实端口；选择刷新不取消待执行的两帧布局校正。
- 暂停、文档替换、销毁后入口遵守原所有者边界；选择刷新不增加保存调用、PUT、撤销或重做记录。

既有 7 项框选浏览器回归继续覆盖 Ctrl／R、空框、重选、缩放平移命中、草稿、滚动、焦点、真实音视频播放及元信息更新。数值几何容许误差为 0.001 世界像素，用于 CSS 序列化和缩放浮点舍入；没有改变生产坐标算法。

工具 `tools/classic_selection_ports_benchmark.cjs` 驱动既有交互诊断工具，生产基线通过 `git archive 2ca5dc9 static` 导出。工具首先断言整个 workspace 文件只有批准的修改，再核对加载资源清单；除指定 workspace 修改外，文本内容只允许已有 CRLF／LF 差异，二进制内容必须相同。

没有诊断页面的渲染器替代或端口缓存原型。两版实际生产代码均在原 HTML 上运行，使用相同的合法 100／1000 节点扇入图和可信 Ctrl 手势，交替选中 node-0 与空框清空。每组 2 次预热；主测每组 16 个正式样本，小图尾延迟另设每组 64 个正式样本。每个阶段第一批基线→修改版，第二批修改版→基线。重型 CDP profile 单独采集，不进入百分位；性能采样期间不同时运行回归。

每次断言选中结果、原选择呈现调用次数、节点 DOM 替换为零，保存调用和 PUT 为零。同步计时从真实 mouseup 到处理栈之后的微任务；第二帧到第二个 RAF，是调度机会而非物理显示延迟。完整逐次样本、环境、资源哈希、trace 和反转顺序另存新性能记录，不覆盖先前诊断或框选快照。

共 **384 个轻量正式样本、24 次预热、12 个独立 profile，合计 420 次真实框选**。每次仍读取实时端口，1000 节点 profile 两版均为 1000 次端口读取。独立 trace 中，两批同步布局由基线 **93.0／97.2 ms** 降至修改版 **0.35／0.46 ms**；修改版仍有 **153.0／185.7 ms** 同步样式计算。类别有包含关系，不将布局、样式、portPoint 包含时间与函数总时间相加。

环境为 Windows 10.0.19045、Ryzen 5 5600XT／12 逻辑核、Node 24.18.1、Headless Chrome 153、1280×900。[完整性能记录](classic-selection-ports-performance-2026-10-05.json) 包含两阶段 AB／BA 执行顺序和所有原始数据；原始运行日志为 `.local/classic-selection-ports-benchmark.log`。
