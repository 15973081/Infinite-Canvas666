# Smart 音频预览会话与播放器所有权

日期：2026-10-04。当前状态复盘和逐项盘点已单独提交为 `cef0342`；Smart 视频截取阶段为 `9a93f96`。本阶段仅整理 Smart 音频预览，不修改两份盘点快照或原始盘点。

## 状态与协作边界

Smart results 的 `createSmartAudioPreview()` 唯一持有面板开关、节点/外部音频来源、标题、原生 audio、三个专属 DOM 引用及自身监听。入口移出 `smartAudioLightboxState` 和三个 DOM 绑定，只初始化 `smartAudioPreview` 并绑定控件。

功能对象和 UI 状态快照均冻结；快照仅包含打开、目标有效、来源类型、节点 ID、索引、暂停和销毁等标量，不暴露节点对象、DOM 或播放器。打开和目标有效分开表达，目标失效不能阻止关闭。

| 范围 | 所有者与操作 |
| --- | --- |
| 音频会话、标题、专属 DOM、播放器、自身监听 | results 的 smartAudioPreview |
| 节点、选择、查看计时及保存 | workspace 的具体目标激活操作，沿用原处理；未整理全局选择 |
| 图片/视频目标与分组导航 | 原 smartImageEditor；音频不是第二份图片/视频预览目标 |
| 普通预览播放器及呈现 | 原 smartPreviewGestures，不由音频功能释放 |
| 删除节点/清空媒体 | document 通知 `closeForNodes()`，不读取音频字段或 DOM |
| 虚拟化与 Escape | workspace 使用 `isPreviewingNode()` 和只读 `state.open`，按原共享事件流程委托 |

## 完整命令与入口差异

`openNode()`、`openExternal()` 各自完成原完整打开操作，包括关闭图片编辑器、释放旧播放器、设置来源和标题、创建与配置 audio、插入与打开。外部引用分支只调用 `openExternal(ref)`，不再自行设置字段或创建播放器。

关闭、下载、目标查询、删除通知、数据变更通知、重置、绑定、暂停、恢复和销毁都有明确入口。旧的打开/关闭/下载函数保留薄委托；旧播放器释放函数委托完整重置，当前生产调用方不再单独组合它与打开操作。

节点打开先验证音频，再由 workspace 执行原选择和查看计时行为。引用匹配到节点时仍走 `openImagePreview()`，原 `try/finally` 恢复选择对象不变。外部 URL 保留标题默认值、选择不变及无节点下载行为，未新增下载或节点创建。

重构前后均在生产页面核对了下列差异：

| 入口/条件 | 原行为及本阶段保持的行为 |
| --- | --- |
| 首次查看已有 `runFinishedAt` 的完成节点 | 修改选择、隐藏查看计时，调度一次保存 |
| 重复查看已隐藏计时的节点 | 仍修改选择，不追加该项保存调度 |
| 尚未完成或正在运行的节点 | 不隐藏计时，不由查看操作调度保存 |
| 节点引用预览 | 恢复原选择，仍保留查看计时可能产生的一次保存调度和节点下载 |
| 无节点外部音频 | 不修改选择，不隐藏节点计时，不调度节点保存；下载按钮仍无节点下载动作 |
| 只读节点查看 | 保留原查看与下载效果及保存入口调用；原权限保护阻止产生脏稿和提交写入 |

未改变保存时机或把保存次数统一断言为零；保存、权限、生成与画布撤销核心均未修改。

## 目标与生命周期

节点目标固定画布 ID、节点对象、索引及源 URL。目标操作核对仍在当前画布、节点仍是原对象、索引仍对应同一音频来源。下载读取验证后的当前条目，避免使用过期元信息。

既有保存流程会复制媒体元数据，因此同一节点、索引、URL 的元数据复制仍视为同一音频。真实浏览器验收覆盖保存期间播放不中断；没有为维持引用身份改动保存流程。节点对象替换、索引移位、音频变为其他媒体或 URL 替换会使目标失效。

删除及清空媒体直接通知关闭。全量 render 和局部 refresh 在数据边界通知音频功能核对目标，覆盖撤销、草稿恢复及媒体替换；加载新文档时重置。查询本身不修改会话。即使目标失效且尚未通知，下载与虚拟化查询也拒绝把它当作有效目标，真实 Escape 仍能关闭并释放。

换源和关闭会解除本播放器监听、暂停、移除 src、调用 load 并移除 audio。元数据、播放和播放进度事件核对会话代次及播放器身份；旧来源的迟到事件不能关闭或恢复新会话。不新增轮询、定时器或动画帧。

控件和 pagehide/pageshow 的监听有显式解绑记录，重复绑定先清理自己的旧监听；关闭保留面板可再次打开的控件，播放器监听释放。缓存离开关闭并释放音频、暂停自身控件；返回只恢复监听，不恢复窗口或播放。永久离开销毁控件、播放器、生命周期监听及 DOM 缓存，之后调用无效。

只清理音频自身记录的监听，保留共享键盘、workspace、图片编辑器、视频截取和其他控件的监听。

## 保留范围与风险

本阶段不处理 Classic 音频、全局选择/composer、其他媒体功能、生成、保存核心或服务端版本一致性。同 URL 原地替换文件内容无法仅凭前端来源信息识别；需要独立版本协议，未在此扩展。

本轮没有跨浏览器、长音频/大文件性能、音频设备听感或真实远端媒体服务验收。测试验证原生解码、播放时间推进和资源释放，未评价音频质量。
