# Smart 全景预览状态与资源所有权

日期：2026-10-04。上一阶段 Classic 结果预览已单独提交为 `6f6f2b8`。本阶段仅整理 Smart 全景，未修改原始盘点与两份复盘文件，未引入框架。

## 范围与收益

results 的 `createSmartPanoramaPreview()` 唯一持有交互会话、专属控件引用、Three 初始化、纹理、渲染器、场景、相机、球体及帧调度。入口原来的 `panoramaState` 有 20 个字段：删除未使用的 `ctx`，其余 19 个移入闭包；静态比例表也留在功能内部。入口只初始化功能对象，原脚本顺序不变。

移除可写的 `window.__smartCanvasPanoramaState`。功能对象和 UI 快照冻结，快照仅含标量，不暴露 DOM、GPU、图片对象或内部拖动记录；比例和分辨率查询也返回冻结的副本。没有建立第二份编辑目标或通用渲染控制器。

workspace 的鼠标移动、松开从直接修改拖动、角度与 DOM 收敛为 `moveDrag()`、`endDrag()`。普通预览和编辑器通过查询、呈现与生命周期命令协作，编辑器不再写全景按钮的显示状态。全景自行绑定窗口 resize，编辑器移除重复的全景 resize 委托，其他工作区监听保留。

| 范围 | 唯一所有者与协作方式 |
| --- | --- |
| 开关、旋转、视角、比例、拖动、全景控件 | results 的 smartPanoramaPreview |
| Three 导入、纹理、渲染器、球体及帧循环 | 同一功能内部；外部不能取得资源引用 |
| 图片目标、分组索引、原图缓存 | 原 smartImageEditor；全景按需查询，不复制目标 |
| 普通图片/视频、对比、元信息与普通预览手势 | 原 smartPreviewGestures；全景通过已有呈现操作连接 |
| 节点、选择、画布撤销与保存 | workspace 的 `applySmartPanoramaExport()` 保留原操作顺序 |
| 已提交编码、上传及写回信息 | 导出任务独立持有，不能由 UI 关闭取消 |

## 操作与三类生命周期

完整操作包括开关/关闭、比例和自定义比例、重置视角、纹理重试、拖动开始/更新/结束、滚轮缩放、导出、绑定、暂停/恢复与销毁。原有 UI 函数名保留薄委托；GPU 初始化、绘制和释放函数不再是全局函数。

**交互会话**：关闭、切图、离开预览模式、目标失效或编辑器退出会撤销帧、结束拖动、使加载代次失效并释放纹理。关闭不以目标仍有效为前提。重复绑定只替换自身监听；不移除共享的鼠标、键盘、其他媒体及工作区处理器。

**渲染资源**：普通开关和编辑器关闭保留渲染器/场景/球体供下次复用，释放旧纹理。缓存页面离开与永久销毁释放纹理、几何体、材质、渲染器和 WebGL 上下文，清理记录先于 dispose，重复销毁不会再次释放。缓存离开时替换自身 canvas，因为已丢失的上下文不能在原 canvas 上重新初始化；返回只恢复监听和控件，用户再次打开时才重建 GPU，不自动开启全景。生命周期沿用编辑器已有 pagehide/pageshow 链，没有另建页面退出处理器。

Three 导入使用原有前端版本 URL；多个初始化等待同一导入。纹理和初始化结果同时核对加载代次、编辑器会话、模式、目标节点与来源，旧结果不能创建新会话资源或写回当前视图。帧回调核对句柄与代次，失效回调不能排入新帧。

**已提交导出**：在调用原生 `toBlob()` 前固定画布 ID、文件名、输出尺寸和放置位置。编码和上传继续完成，即使面板关闭、源目标删除或 UI 销毁。返回后仅在原画布仍为当前画布且允许编辑时新增节点；换画布或变为只读时保留上传结果并提示文件地址，不写入当前画布。任务完成不重新打开面板，也不读取旧 DOM。未引入导出忙碌锁或改变并行提交规则。

保存会复制图片元信息。因此编辑器提供只读全景来源、加载与回调保护接口，允许同一节点/索引/URL 的元数据副本继续显示和交互；编辑器原有 `targetValid()` 及编辑写回的条目身份校验不变。节点对象替换、换来源或换画布仍使全景目标失效。

## 行为保持与验证

真实 Chrome/WebGL 基线及重构后均为：默认输出 1536×864，FOV 75，测试原图中心像素 `[34,136,68,255]`；导出新增一个节点、一次撤销记录和原有两次保存调度（创建节点一次，导出后一次）。不能将保存次数统一改成一次或零次。

比例、分辨率、纹理应用、视口尺寸和投影绘制函数与整理前逐项比较，除生命周期保护和 DOM 访问入口外算法一致。球体半径 500、96×64 分段、反向缩放、透视近远平面、色彩空间、1536 最长边、拖动系数 0.18、俯仰 ±85、FOV 35–100、缩放系数 0.92 均保持原值。

新增验收 `tests/smart-panorama-ownership.cjs`（4 项）和 `tests/smart-panorama.browser.cjs`（19 项），浏览器加载真实生产页面与 Three，使用原生 WebGL 绘制、像素读取、PNG 编码及实际视频播放。只模拟服务端响应；没有替换 WebGL 渲染器。覆盖：

- 冻结快照、私有状态与 DOM、外部命令边界及编辑写回校验保留。
- 输出像素/尺寸、比例、拖动和缩放、重复绑定、反复开关及 GPU 缓存。
- 保存产生的同源副本、分组切图、编辑/预览切换、全景切到视频再返回。
- 节点、URL、画布替换后的帧停止和真实 Escape；拖动中关闭。
- 延迟 Three 导入、延迟原图、关闭重开与快速切目标，只有当前纹理生效。
- 缓存返回不自动开启，重新初始化真实上下文；永久销毁、重复释放及资源唯一性。
- 编码中改变来源与比例后文件/像素/位置/尺寸仍正确；上传中关闭、删除目标、销毁、换画布与权限变化。
- 上传失败重试、只读提交无上传及每次写回原有保存/撤销次数。

原 CORS/原图共享测试仅适配新的编辑器查询接口，继续保留真实跨域缓存、裁剪导出和 WebGL 上传验收。全量回归发现既有音频测试的自动保存计时竞争，改为明确调用 `saveCanvas({force:true})`，保证确实执行所断言的元信息复制；没有修改生产保存逻辑。

最终验证结果：全量 JavaScript **1102 项通过**，相关 Python **51 项通过**，包含新增 **23 项**验收（4 项所有权测试、19 项真实 WebGL 浏览器测试）；48 个 JavaScript 文件语法检查与差异检查通过。Python 仅有既有 Starlette/httpx 弃用提醒。原始盘点及两份复盘文件保持本轮开始时的内容。

## 剩余范围与风险

节点、选择、composer、生成、视频截取、画布撤销、权限与保存核心仍由原模块持有。本阶段没有合并 Classic/Smart、重构普通预览系统或继续处理服务端版本一致性。

真实 WebGL 验证基于本机 Chrome；未覆盖全部浏览器/GPU 驱动、设备自然上下文丢失和大图显存/耗时基准。编码使用原生浏览器实现，上传及保存接口回执为测试响应，未验收真实远端上传服务或生成服务。原动态模块导入失败的浏览器缓存策略及跨客户端版本一致性仍属独立问题。
