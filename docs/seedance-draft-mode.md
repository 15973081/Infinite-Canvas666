# Seedance 2.5 样片与正式视频

支持国内火山引擎官方 `doubao-seedance-2-5-260628`。供应商协议选择火山引擎，Base URL 使用 `https://ark.cn-beijing.volces.com` 或带 `/api/v3` 的地址。成员端通过服务端能力标记显示入口，无需暴露供应商地址或密钥。聚合平台不会仅凭模型名称开启样片功能。

## 使用

1. 选择 Seedance 2.5，填写提示词，比例设为 16:9。
2. 普通画布：勾选视频节点的「先生成 480p 样片」。智能画布：在「样片 / 升级」菜单开启样片模式。开启时默认设置为 5 秒，并锁定 480p；时长可按模型规则调整。
3. 点击生成，等待成功，在输出视频中检查画面。此时不会自动升级。
4. 普通画布：在 output 内播放想要的样片，然后点击**该视频卡片**的「升级 1080p」（另行计费）。多个样片各有独立按钮，不依赖列表序号，也不使用生成节点最后一次任务。智能画布：选中样片输出，在「样片 / 升级」菜单确认对应样片并升级。
   普通画布的按钮在提交后显示「升级中…」，其他样片仍可操作。完成后正式视频加入同一个 output，原样片保留，按钮变为「查看 1080p」并打开对应成片，不再提交付费请求。失败可重试，过期样片禁用升级。
5. 正式视频作为独立任务生成，保留原样片。刷新页面、服务重启后仍可恢复任务和样片身份。样片任务从上游 `created_at` 起 7 天内可升级；过期后需重新生成。

两步分别计费。升级使用样片原供应商、账号和模型，与当前输入框的提示词及参考素材无关。升级计费中的视频输入条件沿用样片原始参考视频，样片本身不算参考视频。

## 饮料广告测试提示词

电影级商业饮料广告，写实摄影风格，时长 5 秒。

一只透明的矮玻璃杯放在深色大理石桌面中央，杯中装有琥珀色气泡水和几块透明冰块。暖金色侧逆光穿过玻璃杯，杯壁上的水珠清晰可见。

0–2 秒：镜头从杯子的近景缓慢推进，一颗晶莹剔透的球形冰块从画面上方落入杯中。

2–4 秒：冰块撞击液面，真实的水花向上飞溅，细小气泡迅速上升，杯中的冰块发生自然碰撞与旋转。液体运动符合真实物理规律，不出现穿模或不合理变形。

4–5 秒：水花逐渐落回杯中，镜头平稳推进至玻璃杯特写，暖金色高光在玻璃表面流动，画面定格在精致、通透的产品质感上。

镜头运动平滑稳定，浅景深，真实材质，电影级布光，高动态范围，商业广告摄影质感。整个镜头保持同一个玻璃杯、同一场景和连续的动作，不切镜，不出现文字、字幕、Logo 或额外物体。

## 接口约定与验证

`POST /api/canvas-video-tasks` 创建样片时传 `draft: true`、`resolution: "480p"`，其余提示词、时长及比例沿用普通视频接口。成功结果新增 `seedance_draft`，包含本地任务 ID、上游任务 ID、原供应商、模型和有效期，随输出素材保存。

升级传 `draft_source_task_id`（本地样片任务 ID）、原供应商、模型、`resolution: "1080p"` 和用于本地记录的 `prompt`。后端从持久化任务读取可信的上游 ID，验证状态、模型、供应商、账号绑定及有效期。上游请求仅包含：

```json
{
  "model": "doubao-seedance-2-5-260628",
  "content": [{"type": "draft_task", "draft_task": {"id": "上游样片任务ID"}}],
  "resolution": "1080p"
}
```

测试：`python -m pytest tests/test_seedance_drafts.py`；浏览器回归：`node --test tests/seedance-drafts.browser.cjs`（需要 Playwright 和 Chrome）。测试拦截上游请求，不调用付费生成接口。

规则核对来源：[Seedance 2.5 官方教程](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)，2026-10-27。
