# 智能画布：样片与成片

调用流程参考 `codex/seedance-draft-upgrade`，交互采用 Pixmax 的视频阶段标识与“生成成片”操作。

1. 在视频生成节点选择支持的火山引擎官方 Seedance 2.5 模型。
2. 在“视频阶段”选择“样片 480P”。开启时默认 5 秒，分辨率固定 480P，时长仍可按模型能力调整。普通模式沿用原有生成流程。
3. 生成结果显示“样片 480P”。选中该样片，点击工具栏“生成成片”，确认生成 1080P 成片。两个阶段分别计费。
4. 新视频节点放在原样片右侧，相隔 60 个画布单位，并保留连线和原样片；任务处理中沿用画布现有的进度与恢复功能。
5. 成片完成后显示“成片 1080P”；再次操作原样片会查看对应成片，不重复提交。样片身份随素材保存，支持刷新后继续操作。

仅对配置了官方国内火山接口、且允许 480P 的模型显示样片入口。升级使用原样片的任务、供应商、模型与账号，不使用当前输入框的提示词或参考素材。样片任务有效期为上游创建时间起 7 天，过期后需重新生成。

## 请求与恢复

样片通过现有视频接口传入 `draft: true`、`resolution: "480p"`。持久化结果中的 `seedance_draft` 保存本地任务 ID、上游 ID、原供应商、模型与到期时间。

成片请求只需本地 `draft_source_task_id`。服务端从原任务解析上游 ID，校验成功状态、供应商、模型、账号及有效期。发送给上游的内容仅包含模型、`draft_task` 和 `1080p`，不会上传修改后的参考素材。计费保留原始参考视频和时长条件。

提交响应丢失时，使用原任务 ID 查询；确认不存在后仍使用相同 ID 重试，避免重复创建付费任务。原任务明确失败后，用户可再次生成。
