## 逐项验收结论

1. **任务 finalizing 恢复：已实现并验收已保存来源的恢复**。供应商结果在下载前保存到私有、固定版本的结果来源对象；每个任务/输出序号对应固定媒体 ID，消费者优先恢复来源，不调用生成或轮询接口。图片、通用视频、Agnes/玉玉视频接入。实库故障测试覆盖多图中断、来源完成但状态提交丢失、ready 输出复用、旧租约、来源过期、五次重试上限和受控人工重试。视频 token 用量及价格快照恢复前后一致。尚未完成来源持久化的供应商响应不能凭空恢复，保持不盲目重新付费的边界。
2. **任务规范请求：已实现并验收**。新增 `task_requests.py`，将已知旧路径、本站相对/绝对签名 URL 和已登记固定版本 TOS URL 转成稳定媒体引用；保留提示词、供应商标识与未知外链。扩展密钥字段剔除，创建任务时锁定并校验 ready 输入，执行前复验，成功提交时拒绝未 ready 输出。固定实际供应商与 `provider_account_ref`，账号配置变化后进入待核对，不提交/轮询其他账号。图片 API 补齐 `client_task_id`；图片/视频同键签名变化可重试，不同内容返回 409。新增 9 项实库验收，总计 45 项通过。历史导入显式保留旧请求及未知账号，不伪造过去的账号身份；完整迁移审计仍见第 4 项。
3. **长历史与列表：已实现本地范围的有界读取**。图片历史新增 `/api/history/page`，PostgreSQL 按时间戳/ID 游标查询，每页最多 200 条，migration 003 提供索引；五个图库“加载更多”实际请求下一页。旧数组接口保留、SQL 限定最多 5000 条。对话列表按用户过滤，每页最多 200 条，只返回摘要并支持加载更多。文档/管理扫描按 ID 分批释放连接，画布目录只传元数据，不读出整张画布正文；素材库按设计保留单文档树形兼容结构，不声称其已分页。新增 4 项实库与 2 项前端验收。浏览器首屏 24 条、下一页共 35 条、尾页结束，证据 `.local/cloud/acceptance/paging-check.json`，人工记录已清理。当前全量为 49 项实库、120 项 Python、158 项 CJS 通过。
4. **迁移审计：已补齐服务端类别与报告验收**。首次目标写入前盘点画布、备份、素材及输出、目录、提示词、供应商配置、维护状态、两处对话、历史、任务 SQLite 和五张账本表。报告提供类别数量/字节数、文件哈希/命名空间/版本及带源文件和 JSON 指针的引用问题；外链去掉凭证及查询参数并标记未验证，不自动下载。未知 JSON 与提供的 `localStorage.json` 标记待人工核对；没有浏览器导出明确标记未提供，服务端完成状态不代表浏览器数据已迁移。新增 3 项离线测试；扩展实库用例验证备份/对话/维护导入及任务源费用变化拒绝覆盖。全量 Python 120 通过、45 跳过、7 项 subtest 通过；45 项实库测试另行全部通过。未执行真实旧数据迁移。
5. **本地恢复演练与备份对象字节：已完成**。开发库备份 `.local/cloud/backups/20260914-054255.dump` 携带 7 个对象共 10,029,722 字节。离线恢复到 `.local/cloud/acceptance/restore-20260914-054255/objects` 后，在新建隔离数据库中读取普通/智能画布并导出含原件 ZIP，逐个哈希一致，报告同目录 `report.json`；隔离验收数据库已移除，开发库与原对象保持原状。真实云端 TOS 恢复版本重映射、异地备份及定时部署仍属于外部部署边界。
6. **回归测试基线：已修复并复验**。最终全量 Python **120 通过、52 项云集成跳过、7 项 subtest 通过**，全量 CJS **158 通过**；另行运行的实库集成 **52 通过**。先前回归夹具修复保持 loopContext/graph 和任务 ID 等行为断言。
7. **总体本地验收：已完成**。设计第 10 节 A–D 证据及边界见[最终验收](postgresql-tos-acceptance.md)。真实供应商网络拉取、真实 TOS 权限/配额/网络和云端容量测试保留为外部联调边界；当前完成结论限定 PostgreSQL + `.local` 对象模拟。最后补齐两种画布文字引用边界，以及页面/API/WebSocket 登录、异源保护与退出失效测试。
