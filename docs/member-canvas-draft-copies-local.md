# 草稿另存副本：实现与验收

2026-09-14，C3 第十二批。完整线上迁移仍未完成。

## 本批实现

- 经典和智能草稿列表提供“另存副本”“重试 / 确认副本”和“打开副本”。版本不同或原画布正在被他人编辑，也可凭当前空间的新建、画布读取、素材读取权限创建副本；不领取或改变原画布租约。
- POST /api/canvas-draft-copies 接收 UUID request_id 和结构化 document。只接受标题、图标、类型、节点、连线、视角和设置；不继承原 ID、revision、目录、回收站标记、成员身份或费用日志。节点待执行/运行状态被移除，工作流参数与已完成媒体内容保留。
- migration 009 追加 canvas_draft_copies。权限及维护检查、同请求串行锁、完整画布创建、当前空间已就绪素材引用、重试回执和审计均在同一个数据库事务完成。中途失败回滚全部，不留下空白画布。原 migration 001–008 未修改。
- 请求回执按空间、成员及请求 ID 唯一。同一请求和内容返回原副本，同请求不同内容返回 409；副本后续被编辑，重试不覆盖编辑；副本进入回收站后，重试提示恢复原副本，不再创建新画布。
- 客户端从源草稿键和内容派生稳定请求 ID，发送前保存独立副本请求草稿。网络响应丢失、页面重新打开或另一页面重试仍使用相同请求；当前页继续修改自己的草稿不会擦掉这份请求记录。原草稿保留，不持久化租约凭证。
- 打开副本前，当前编辑按正常流程保存并结束；无编辑资格的未保存页面仍需明确导出后离开。新副本打开时为查看模式，继续编辑须主动领取自己的新租约。
- 草稿列表打开前立即暂存本页最新输入，避免 150ms 防抖尚未触发时展示旧内容。独立经典画布跳转智能画布、智能画布返回目录，都保留显式空间参数。

## 浏览器验证

使用临时 workbench_ui_7c4606f04c5e4f31b7618b6b72913aee schema，预置本地测试账号登录设计空间。

1. 经典画布输入“经典草稿另存副本验收内容”；独立另一页面读取本地草稿，确认另存并打开，副本标题带“草稿副本”，提示词完整、打开后查看模式。原画布仍由原页面持有，不因复制转移编辑资格。
2. 智能画布创建提示词并输入“智能草稿另存副本验收内容”；从草稿列表确认另存，打开后的提示词完整，费用为零，页面处于查看模式。未点击任何生成按钮。
3. 重载后从独立智能画布返回目录再打开原智能画布，两个地址均保留设计空间参数，无需重复选择空间。草稿中的已完成副本请求可再次确认。
4. 数据库复核仅有两个副本回执，对应 classic/smart 各一张 revision=1、各一个节点；设计空间共四张画布，制作空间仍为两张，没有重试产生的重复副本。
