# 管理平台画布占用：本地实现与验收

更新：2026-09-14，第 30 批。无新 migration。

## 管理行为

独立管理平台增加“画布占用”页面。必须明确选择一个空间，并同时持有该空间 canvas.read 与 canvas.lock.takeover 权限；仅有管理入口、平台超级管理员或普通编辑权限不自动获得跨空间占用操作权。只持有画布读取/接管权限的自定义角色也可以登录管理平台访问此功能。

列表按画布编号分页，显示有过编辑记录的画布及其最近一次占用，区分正在编辑、已结束、已到期和资格失效。当前编辑者按现有登录会话、成员状态、授权版本、空间资格及读取/编辑权限复验。返回标题、类型、回收站状态、成员编号/昵称、代次、版本及时间；不返回画布正文、登录或编辑会话编号、令牌或哈希。已物理清理的画布不列出；查询不创建或续期租约。

“结束占用”需填写原因并勾选明确确认。提交绑定列表展示的画布、空间、编辑代次和已保存版本；操作时在权限事务中再次校验，按画布→租约顺序锁定。期间保存、接管、到期、撤权或另一次结束会拒绝旧确认，不能用旧表单结束新的占用。错误显示在弹窗内，需关闭并刷新后重新核对。

成功时递增代次并标记租约结束，同一事务写 collaboration_events 与 management_events。审计包含操作者、目标空间/画布、原成员、前后代次、版本及原因。审计失败整笔回滚；重复旧确认不会重复写审计或影响新租约。现有单向令牌哈希随历史字段保留，旧凭证由新代次和结束状态同时阻断，不生成替代编辑凭证。

管理操作不保存文档、不创建“保存并结束”快照、不修改任务和费用。原页面通过状态订阅/后续请求获知失效，停止编辑并保留草稿；需要编辑的成员仍须在工作台重新领取资格。后台结束占用不等于代替成员保存，也不证明可停库。

此项属于管理控制，可在排空期间结束现有占用，但不解除维护限制或恢复编辑；只读及离线转换已撤销的占用会作为状态变化拒绝再次处理。已过期或失去授权的记录仅展示，不提供伪装为有效编辑的结束按钮。

- PostgreSQL 全量 299 通过，新增 8 项/参数场景。覆盖双画布真实 HTTP/WS 撤销通知、旧保存/续租拒绝、新租约不受旧确认影响、文档和保存快照保持、双审计、跨空间和角色隔离、管理/工作台会话区分、来源检查、即时撤权、分页及失效持有者、排空与待交接失效、审计回滚、保存与撤销并发只能一方成功。

- 浏览器使用独立 localhost:8772 工作台与 localhost:8773 管理进程，共享本轮隔离 schema。经典、智能画布分别保存提示词并显示占用；经典确认框打开后再次保存，旧表单被拒绝。刷新后分别结束两张画布占用，两页面自动停止编辑，文本仍在且只读。管理审计显示两条操作及原因，切换制作空间后列表无设计空间记录。
- 数据库逐项比较结束操作前后的四张画布编号、版本、完整文档，全部一致；两条租约从代次 1 变为 2，两条管理审计，0 生成任务、0 付费提交。验收未调用真实模型。
