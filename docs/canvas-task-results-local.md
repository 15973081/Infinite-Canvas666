## 已实现

双画布协作栏新增“生成结果”。同空间且具有画布、任务、素材读取权限的成员可查看该画布已完成的图片/视频结果；当前编辑者可加入为新结果节点。加入前先保存当前更改，后端在同一事务校验权限、维护状态、编辑凭证、画布 revision、任务归属与素材可用性，更新画布及引用索引并记录协作审计。重复确认不重复加入，不重新生成、不新增费用，也不覆盖旧生成目标。

任务结果来自持久任务和已发布素材，不接受浏览器传入的任意结果。已删除或未迁移素材显示不可用，原任务保留。列表每页 30 项；只有实际结果素材仍在画布中才标记已加入。经典与智能画布的恢复轮询校验页面、编辑代次及目标是否仍存在，交接后的旧结果留待当前编辑者明确加入。

## 图片不显示的原因和修复

用户原“111”画布中的图片请求缺少空间参数。成员网关返回 HTTP 400、workspace_required；同一原件加 workspace=default 后返回 HTTP 200、image/png，265339 字节。原素材处于 ready，文件未丢失。

成员请求封装可为 fetch 添加空间头，但 img、video、audio 和 Image 对象不会自动携带这些头。新增 MemberMediaUrl，将同源素材预览、原图回退及灯箱地址绑定当前成员与空间；存入画布的稳定引用保持原值。实际 HTML 注入脚本在业务脚本之前加载。

本地文件签名地址的成员身份参加 HMAC；浏览器专用签名经过成员网关再验证，删除或替换成员参数均拒绝。供应商所需的独立签名能力保持。此验证范围是本地文件模拟；原生 TOS 的签名、撤权与恢复仍按原计划验收。
