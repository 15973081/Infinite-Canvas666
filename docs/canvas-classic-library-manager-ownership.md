# Classic library 管理弹窗所有权

日期：2026-10-05；实施基线 `d9a0a33`。本轮完成剩余管理 UI 的收益核对，只整理有监听/会话收益的 library 管理弹窗。

## 状态与协作

`createClassicLibraryManager()` 私有持有当前 tab、资产/工作流/提示词三个多选 Set，以及两个专属 DOM 引用。入口只创建对象和调用原绑定入口，现有打开/关闭/刷新函数继续薄委托。查询对象及 ID 数组冻结，外部不取得 Set 或 DOM。

库与分类仍归素材/模板面板，管理弹窗不复制选择或内容数据。库/分类切换通知 manager 清理对应集合，提示词切库通知清提示词多选，资产删除通知移除受影响 ID；原命令同时处理共享选择和刷新，调用方无需拼接字段。

保留原差异：打开只清资产与提示词多选，工作流多选保留；切 tab 不统一清空三个集合；资产/工作流库与分类使用原共享素材命令；提示词系统库仍只读。上传字段、批量删除、工作流下载、词库编辑与权限路径沿用原实现，不增加画布保存或修改生成/保存核心。

## 监听与回执

反复绑定先移除自身打开按钮、tab、模态窗口和 pagehide/pageshow 处理器；素材侧栏 drop/导航及其他工作区监听由原所有者清理。当前内容重绘前解绑上次上传控件监听，避免保留旧 DOM；关闭也清理当前内容监听，保留可重新打开的管理入口。

打开加载回执按打开代次核对，只允许当前仍打开的会话更新视图。tab 或复选框操作不丢弃当前会话的数据通知，渲染当前 tab；关闭、重开、暂停、销毁使旧打开回调失效。

已提交管理写操作继续原内容更新。回执只在原 UI 选择代次仍有效时清理多选；重开后的新选择不被旧删除/上传回执清空。关闭后数据通知不重绘隐藏窗口或重新绑定旧上传控件；永久销毁后不恢复 UI，未取消已经提交的服务端写入。词库响应竞争及服务端版本一致性未扩展处理。

缓存页面离开暂停自身交互，保留 tab、多选与开关；返回重新绑定并更新仍打开的视图。永久离开关闭窗口、解绑自身监听、清多选并释放 DOM 引用；后续命令无效。页面中 HTML ID 仍可能由浏览器提供同名 window 属性，这是原 DOM 行为，不是代码导出的引用；生产脚本不再声明或跨功能使用这两个可写别名。

## 保留范围

Classic 管理页搜索、排序、文件夹、移动和删除确认仍由单一入口管理，已具备操作与刷新路径，未发现需要跨模块协调字段的收益，故不为缩短文件再加控制器。Smart 词库缓存、本地预设、分组及覆盖仍沿用原内容存储。复盘中明确记录这些保留理由。
