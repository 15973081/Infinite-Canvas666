# 旧供应商配置导入与本地验收

更新：2026-09-14，第 21 批。独立后台“供应商与分配 → 导入旧配置”支持先预览，再明确选择要新建的配置和需要迁移的凭证。

## 使用与来源

管理进程需应用新增 migration 013；已有开发库须按原备份和迁移流程处理，不能直接跳过 004–012。当前开发 schema 未应用 004–013；本批测试使用隔离 schema。

支持两种明确来源：

- 原共享空间配置：读取当前数据库 default 空间的 workspace_documents 中 api_providers/default 原件；不随管理页面所选空间变化。
- 指定旧文件：维护人员通过 LEGACY_PROVIDER_CONFIG_FILE 指定原 api_providers.json 的绝对路径。浏览器不能提交任意文件路径，未配置时返回明确错误。读取原列表，不使用会补齐默认供应商的运行配置加载器。

可选 LEGACY_PROVIDER_ENV_FILE 指定旧 API/.env 的绝对路径，用于迁移旧凭证。文件里的键名沿用原规则：comfly 对应 COMFLY_API_KEY，volcengine 对应 ARK_API_KEY，其他对应 API_PROVIDER_<规范化ID>_KEY；火山额外读取 VOLCENGINE_ACCESS_KEY_ID、VOLCENGINE_SECRET_ACCESS_KEY。同时支持原配置中的三个已知凭证字段；若内嵌值与文件值冲突，跳过该项，不自动选择账号。

导入器不读取其他进程环境中的模型密钥，也不会运行 .env 内容。仅存放在进程环境中的凭证需由维护人员转为明确的迁移来源，或通过现有编辑页面重新配置。迁移凭证前必须配置并备份固定 PROVIDER_SECRET_KEY，见[供应商配置说明](managed-providers-local.md)；仅导入配置不需要加密主密钥。

每个来源文件最多 2 MiB，配置最多 100 项，重复 JSON 字段、非法 JSON、异常编码或超限整体拒绝。重复供应商 ID、同名已存在、已弃用集成、未知字段、不兼容配置或凭证冲突逐项展示跳过；无效项目不回显原始值或错误正文。ComfyUI、ModelScope、RunningHub 不重新进入可用列表。

## 确认与数据边界

预览展示整理后的配置摘要、旧默认标记、凭证字段是否存在和跳过原因，不返回密钥、凭证预览字符、来源绝对路径或摘要指纹。预览绑定管理成员及本次登录会话，有效期 15 分钟。更换来源或修改原因会清空旧选择；退出、关闭弹窗和迟到响应不会恢复旧结果。

导入配置与迁移凭证分别勾选，默认均不选择。原默认供应商仅作为提示，导入不修改任何空间分配或默认项。导入保留原启用状态、模型、高级配置和价格历史；已有同名配置不覆盖，原文件和原共享配置不改写，历史费用账本不重放。

普通编辑会将输入价格当作“期望的当前价格”合并。本批增加仅内部可用的 create-only 价格迁移模式，完整保留已结束和当前价格的金额、生效区间；不能由管理保存 API 额外传参开启，也不能用于覆写已有供应商。无效价格条目或非 CNY 数据拒绝该项，避免静默丢失或改变币种。

确认时重新核验权限、会话、期限、配置及凭证文件内容和目标是否仍可创建。所选供应商在同一事务中写入；任一冲突或凭证加密失败整批回滚。已完成预览的相同选择重试返回原回执，包括并发确认；改变已完成选择则拒绝，不重复创建、覆盖或追加审计。完成后的回执仍受当前会话和权限校验。

preview 和 complete 审计只保存来源类型、计数、导入 ID、凭证字段名、原因和回执。预览表保存不含凭证的摘要及内部来源指纹，不保存原始文件或明文密钥；真正导入的凭证只进入 managed_providers 的加密字段。来源文件仍须由维护人员按原保密与备份规则管理。
